# Build the requested prose

Use this resource for composition, revision, translation, explanation, medium conversion and prose guidance. Inherit the task boundary and direct-expression rules from [CORE](CORE.md). Select the sections that resolve the current writing choice; return to the assigned artifact owner.

## Select the economic argument

Use the established reader, purpose, medium, central question and permitted content changes. Select the central content the reader needs to understand, judge or act on, and state it in the first sentence. Assign each candidate fact to that content, its reason, mechanism, comparison, magnitude or execution condition. Retain requested items and details whose removal changes the subject, comparison, quantity, logical relation or decision.

Give each paragraph a question or claim. Order its sentences by the relation needed to establish that claim: premise to implication, institution to choice, choice to outcome, or comparison to decision. Supply the source-established relation; a connective alone cannot supply a missing premise. Carry established information into the next claim instead of repeating it. Paragraph count and sentence order follow the argument.

For a contrast, ask whether removing either side changes the conclusion, reason, choice or meaning of a quantity. Remove the side that does no such work and state the remaining proposition directly. Retain comparisons that distinguish explanations, change a ranking or establish the result's magnitude and population. Compress estimates that establish the same claim. In successive English comparisons, state the first comparison and result before introducing the distinction tested next; put that next design and its estimates where the distinction arises. A change of inferential purpose determines the next unit of explanation. Keep units, measured uncertainty and identifying conditions with their claims. Explain a changed specification or assumption when it changes the claim or its conditions.

For a decision, state the feasible choice or switching condition under the adopted objective and constraints, using the premises and calculations that determine the ranking. Include a scenario calculation when requested or when it can change that choice. For unresolved option selection use [DECIDE](DECIDE.md), then return to the passage.

## Establish facts and connect the explanation

Read the source passages or saved results supporting the selected claims. Write each claim as the relation those inputs establish: observation, estimated comparison, implication of assumptions, or proposed mechanism. Carry that relation through the paragraph's conclusion. Put the relevant subject, reference group, quantity, units and period in the sentence that needs them.

Use the same term for the same object. When a subject, pronoun or quantity could refer to different objects with different implications, name the intended object. Replace an ambiguous chain of abstract nouns with the actor, action and outcome established in the source. Introduce a concept through the behavior, comparison or quantity it names. Retain definitions that recover the mechanism or comparison; repeat one only when its referent has become unclear. In Japanese, choose a predicate that states the relation and name an actor when omission changes who acts. In English, use clauses that expose the actor, action and object, with consistent referents and number.

Connect sentences using supported cause and result, derivation, addition, comparison, specification, example or transition to a new question. Use a connective or bridging clause when the relation would otherwise be unclear; use established referents and sentence order when they already convey it. A causal connective requires a supported causal relation. For an established information or incentive mechanism, connect the information or incentive to the choice it changes and then to the outcome. Apply the same relation test to slide headings, bullets and equations together.

When a compound definition obscures whether conditions hold jointly or alternatively, give the requirements separate clauses while retaining their domain, quantifiers, negation and conjunctions. Keep a definition intact when its meaning is already recoverable.

## Select the profile

Select an explicitly requested profile; otherwise use writing_profile in [project context](../../docs/ai/repo_context.md), with [default-micro](../profiles/default-micro/PROFILE.md) as the default. A supplied passage becomes the profile only when the user designates it as such. Change the project selection only on a request to adopt or switch profiles.

Read the selected profile's principles once. For an unresolved wording, connection or passage-function choice, read the example for the needed language and function. Read an extended Introduction only when cumulative reasoning across paragraphs is needed; reading one language does not require its counterpart. Reuse an already read version. Stop reading when the current choice can be made. Research sources supply factual claims; fictional profile examples supply writing operations. Create or revise a profile only on an explicit request; saving it does not adopt it. New examples contain fictional inputs, finished outputs, the decision being taught and a generalizable rule. Profile creation or revision belongs to [econ-writing:profile](../skills/econ-writing/SKILL.md).

## Preserve meaning across languages

During composition and the existing reread, compare the text with its inputs: actors, actions, quantities, signs, comparison, causal or associational relation, tense, negation, quantifiers, joint or alternative conditions, timing, units and uncertainty. Preserve obligation, permission, ability, feasibility, actual choice and implementation as distinct propositions. Express a reported hypothesis as a hypothesis and an estimated result as an estimate with its target and units. Do not invent a relationship to connect sentences.

For revision, translation, explanation and medium conversion, change substantive content only within the user's authorized scope. Use natural target-language syntax while preserving the claims and paragraph functions. Resolve an ambiguity from the authorized sources; ask about it only when it changes the requested meaning and cannot be resolved from those inputs.

## Finish the passage

In the owner's existing reread, remove sentences unused by the answer and repeated information, name unclear referents, repair missing source-supported connections, and apply the contrast test in Select the economic argument. Compare revised, translated, explained or converted text with its input for unintended substantive changes. Return the requested finished text and format when complete. Add change notes or alternatives only when requested; this reread does not require another reviewer.
