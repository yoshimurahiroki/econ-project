# Default economics writing profile

Profile ID: default-micro. Languages: English and Japanese. Use for economics explanations, research sections and decision-oriented prose. Apply [PROSE](../../runtime/PROSE.md).

## Principles

Connect institutions, data, methods and findings through their economic roles. Explain how the setting and comparison answer the question and what the result means. Relate actors' incentives and feasible choices to measured outcomes. Explain the economic forces behind competing predictions and select observed results that distinguish them.

Identify the displaced activity when explaining an activity's return. Define a decision rule's information set when explaining its choice. Use the common information-selection, sentence-connection and meaning-preservation rules in PROSE.
