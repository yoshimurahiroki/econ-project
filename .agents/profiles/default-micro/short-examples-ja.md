## 結論と比較

Example ID: default-micro.ja.conclusion.

**Input:**
1年間の純便益を最大にするサービスを一つ選ぶ。送迎サービスの便益は8万4,000ポンド、費用は6万ポンド。自転車サービスの純便益は1万9,000ポンド。両案の費用は予算6万5,000ポンド以内で、実施枠は一つである。

**Ideal output:**
送迎サービスを採用する。1年間の便益8万4,000ポンドから費用6万ポンドを引くと、純便益は2万4,000ポンドになる。自転車サービスの純便益1万9,000ポンドとの差は5,000ポンドである。両案の費用は予算6万5,000ポンド以内に収まるため、純便益の大きい送迎サービスに実施枠を配分する。

**Generalizable operation:**
選ぶ行動を冒頭に置き、共通の期間と通貨で純便益を計算する。予算内の選択肢を同じ目的で比較し、選択を決める差額を示す。

### 実験結果からConclusionを書く

**Input:**
独自の架空事例。シーダープレインの48自治体には、各100世帯、計4,800世帯の給付対象世帯がある。24自治体を無作為に選び、担当者が申請期限と窓口所在地を記した通知を対象世帯へ送った。8週間以内の申請完了率は通知を割り当てた自治体で42％、対照自治体で34％。保存済みの割当て効果は8パーセントポイントで、自治体単位のクラスタリングによる95％信頼区間は3〜13パーセントポイントである。

**Ideal output:**
申請期限と窓口所在地を記した通知によって、8週間以内の申請完了率が8パーセントポイント上がった。48自治体への無作為割当てにより、対象4,800世帯の反応を推定した。この結果は、シーダープレインで行政による通知が期間内の申請を増やすことを示す。

**Generalizable operation:**
観測した行動の変化と、その変化を特定する比較を結論へつなぐ。介入、アウトカム、期間、対象世帯を一貫して保持する。

## 制度と機序

Example ID: default-micro.ja.mechanism.

**Input:**
協同組合は共同の製粉機に午前と午後の利用枠を設けた。午後に自家用車が空く農家は、その車で穀物を運ぶ。外注運搬には料金がかかる。利用時刻と運搬費の関係を説明する。

**Ideal output:**
午後に自家用車が空く農家は、製粉機の午後の枠を申し込み、その車で穀物を運ぶ。製粉の時刻を車の空き時間に合わせることで、外注運搬に支払う費用を省ける。

**Generalizable operation:**
利用申込み、利用できる車、運搬費の順に関係をつなぐ。農家が時間を選ぶ理由を、その選択で変わる支払額から説明する。

### 理論の命題と経済学的機序

**Input:**
独自モデル。2企業が数量q_i >= 0を同時に選ぶ。逆需要はp = a - b(q_1 + q_2)、限界費用はcで、a > c >= 0、b > 0とする。各企業は利潤(p-c)q_iを最大化する。均衡とcの変化に対する反応を説明する。

**Ideal output:**
一意なクールノー均衡では、各企業の生産量は(a-c)/(3b)、市場価格は(a+2c)/3となる。各企業の一階条件はa-c-bq_j = 2bq_iであり、2本の条件を連立すると均衡生産量が得られる。限界費用に対する各企業の生産量の微分は-1/(3b)、市場価格の微分は2/3である。生産費用の低下は、両企業の数量選択を通じて市場全体の供給を増やす。

**Generalizable operation:**
均衡の値を提示し、企業の最適化条件から導出する。同じ式を用いて比較静学の機序を説明し、モデルのパラメータ範囲と均衡概念を保持する。

### 保存済みの推論を伴うResults

**Input:**
独自の架空実験。シーダープレインの48自治体のうち24自治体に通知事業を無作為に割り当て、担当者が各自治体の対象100世帯へ申請通知を送付した。残る24自治体を対照とした。8週間以内の申請完了率は42％と34％。保存済みの割当て効果は8パーセントポイントで、自治体単位のクラスタリングによる95％信頼区間は[3, 13]。掲載箇所は表2第1列である。

**Ideal output:**
申請通知によって、8週間以内の申請完了率が8パーセントポイント上がった（表2第1列）。申請完了率は、通知事業を割り当てた自治体で42％、対照自治体で34％だった。自治体単位のクラスタリングによる95％信頼区間は3〜13パーセントポイントである。これらの推定値は、通知事業の割当てに対する対象4,800世帯の申請行動の変化を表す。

**Generalizable operation:**
効果の大きさを、群別の申請完了率、観測期間、対象世帯、保存済みの推論につなぐ。自治体への事業割当てと世帯の申請行動を、それぞれの主体を明示して記述する。

### モデルの反実仮想と移転の計上

**Input:**
独自の数値モデル。独占企業の週次需要はQ(p) = 120-2p、限界資源費用は20通貨単位である。企業は利潤(p-20+s)Q(p)を最大化する。sは生産1単位あたりの補助金で、基準ケースはs=0、介入ケースはs=10。保存済みの解は(p,Q)=(40,40)と(35,50)。消費者余剰は400から625、補助金収入を含む企業利潤は800から1,250、補助金支出は0から500になる。社会的余剰は消費者余剰と企業利潤の合計から補助金支出を引いた値であり、公的資金の資源費用を1とする。

**Ideal output:**
生産1単位あたり10の補助金を導入すると、モデルの価格は40から35へ下がり、週次生産量は40から50へ増える。消費者余剰は225、企業利潤は450増える。補助金の財源には週あたり500を要する。その結果、社会的余剰は1,200から1,375へ175増える。企業の増産が余剰を生み、補助金の移転は企業収入と公的支出に逆の符号で計上される。

**Generalizable operation:**
モデルに加えた変更と数量の反応を示し、移転を厚生基準に沿って計上する。保存済みのシナリオ値、週次の期間、通貨単位を保持する。

## 割当てと比較

Example ID: default-micro.ja.assignment.

**Input:**
職業訓練の応募者数が定員を超え、受講機会を抽選で割り当てた。当選者と落選者のその後の有給就業を比較する研究設計を説明する。

**Ideal output:**
受講機会の抽選で当選した応募者と落選した応募者のその後の有給就業を比較し、職業訓練を受ける機会を得ることが就業に与える影響を推定する。

**Generalizable operation:**
割当て方法と結果の比較をつなぎ、抽選で付与した機会の効果として推定対象を定める。推定値の意味を説明する場面では、その値を定める回帰式を示す。
