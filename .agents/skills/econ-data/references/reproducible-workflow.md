# Reproducible execution

## Trace inputs and affected dependencies

Trace the requested table, figure or numerical claim to its saved input, sample, specification, code and command. Preserve dependency versions and stochastic seeds. Use the dependency rules in econ-data to recompute calculations affected by a change.

## If replication is requested

For replication, run the requested path and compare its result with the source using a tolerance defined for the quantity. Resolve a mismatch by tracing it to the sample, source version, definition or calculation. Run the full pipeline for a requested clean reproduction or a result that requires its full dependency chain.

## If presentation is requested

For presentation, generate the requested text and exhibits from saved quantities and definitions. Preserve their source and calculation revision. Store presentation revisions, commands and execution results in the existing operational record outside research artifacts.
