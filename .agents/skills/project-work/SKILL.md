## Contribute

Use the contributor's existing project summary/workplan for the assigned propositions, selected priority, required inputs, next action and completion contract. Return the actual contribution and its economic implication, producing inputs and result versions, the decision it enables and the next assigned action. Prepare a needed consultation through the contact section. Incorporate a received correction into the affected calculation and artifact, then return the completed contribution to its parent case.

## Manage

Select `manage` when the user owns the case, its team or shared resources. Read [management](references/practice.md#manage-the-case). Establish the economic intervention and decision rule before selecting work. Connect the supporting propositions to executable assignments, real capacity, dependencies and completion conditions. Compare feasible allocations through their resulting outcomes and costs.

Use the existing state and argument sources for the current answer, its support and the workplan. Compare candidate forecast orders and shared capacity through DECIDE, including information value, displaced work, delay and direct cost without counting the same gain twice. Record the selected allocation in the existing project judgment with current plan bindings and the actual decision authority; execute the returned next task through its specialist. A recorded finding that changes a determining premise changes its model, dependent work and final artifact through the adopted authority. Complete the requested operating decisions, implementation support, acceptance evidence and usable handover. Inspect the resulting outcome against its defined target.
