# Descriptive and model-based work

Descriptive analysis summarizes patterns in data. Model-based analysis uses an economic structure to study parameters, counterfactuals or welfare. The variation and assumptions used in either analysis determine which economic conclusions it supports.

Decide what the requested analysis must establish. For a descriptive answer, choose observed patterns and comparisons that support its economic conclusion. For a model, identify the parameter or counterfactual sought and the variation that can inform it. Use observed behavior to choose which mechanisms require representation and which features can be simplified. Explain how each assumption contributes to the economic result.

Begin with the step that resolves the next consequential research choice. A model can clarify which observations to collect, how to measure a new object or which predictions distinguish a mechanism. Existing observations can identify the patterns a useful model needs to explain. Organize the work around those dependencies and the requested result.

Use existing summaries that answer the requested question. For a sample-coverage question, give counts by the requested periods and groups with the eligible population as denominator. Calculate a new summary through the existing pipeline when that answer requires it. Generate requested captions, numerical text and language variants from the same quantities and definitions.

For a requested model, connect added assumptions and features to its economic parameter or counterfactual. Distinguish internally estimated, externally calibrated and imposed quantities. Descriptive and causal-effect tasks finish at their requested results.
