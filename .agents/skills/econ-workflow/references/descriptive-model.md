# Descriptive and model-based work

## Select the economic object

Descriptive analysis summarizes observed patterns. Model-based analysis uses an economic structure to study parameters, counterfactuals or welfare. The variation and assumptions in each analysis determine the economic conclusions it supports.

Define the economic question. For a descriptive answer, choose observed patterns and comparisons that establish the answer. For a model, identify the parameter or counterfactual and the variation that informs it. Use observed behavior to select the mechanisms the model represents and the features it simplifies. Explain how each assumption shapes the economic result.

## Order dependencies

Order the work by its dependencies. Use a model to specify observations, measurements or predictions that distinguish mechanisms. Use existing observations to establish the patterns the model explains. Record work assignments and unresolved choices in the operational record. Exclude project plans, progress, stages, decision or adoption status and future user decisions from research deliverables, including explanations, annotations and paraphrases.

## Reuse or calculate the requested quantities

Use existing summaries that answer the requested question. For sample coverage, report counts by the requested periods and groups with the eligible population as denominator. Calculate a summary required for the answer through the existing pipeline. Generate captions, numerical text and language variants from the same quantities and definitions.

## Deliver the selected result

For a requested model, connect its assumptions and features to the economic parameter or counterfactual. Identify internally estimated, externally calibrated and imposed quantities. End descriptive and causal-effect tasks at their requested results.
