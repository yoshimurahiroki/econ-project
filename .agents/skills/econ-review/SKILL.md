# Review and results

Review the named object at the requested depth. Read the evidence needed to judge its claims. A full paper review covers main text and claim-bearing appendices. A local review addresses the specified passage, result or operation. Correct text when correction is requested.

Establish each retained issue through its location, evidence and consequence. Use the strongest relevant response in the paper to judge the criticism. Assess severity by its effect on the contribution, estimand, identification, measurement or inference. Give a concrete repair when requested. Use econ-design for the methodological question being assessed.

Interpret the specified result through its parameter, comparison, population, period, units and baseline. Preserve numerical uncertainty. Compute relative changes from a named denominator. Use direct contrasts for subgroup differences. Preserve event windows and composition. Assess mechanism or welfare claims against the evidence and inputs they require.

For a descriptive-model review, connect the observed variation, model features, assumptions and economic object relevant to the claim. Distinguish fit to estimation moments from independent validation. Resolve consequential inconsistencies in units, domains, timing, normalization or derivation through the generating object. Reconcile code, exhibits and prose for the reviewed claim.

For requested referee responses, answer each specified comment with the response, actual change, evidence and location. Distinguish proposed analysis from executed analysis. Edit within the authorized review scope. Use econ-edit for wording-only work. Apply econ-assertive once for final semantic deletion and direct expression.
