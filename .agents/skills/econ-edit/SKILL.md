# Revise specified text

## Purpose and input

For a new economics task, complete the brief [workflow entry](../econ-workflow/SKILL.md#task-entry) once, then continue here. Support calls within an existing task do not restart entry.

Revise specified economics prose for clarity, continuity and natural expression while preserving its substantive meaning.

Input: Specified text and scope; EDIT alone selects the preceding answer.

Apply [the common prose rule](../econ-assertive/SKILL.md#common-prose-rule) to the revised research artifact. Carry out source checks and task coordination outside the artifact.

## Procedure

### Select and revise within scope

Identify the target and requested scope. EDIT alone selects the immediately preceding answer. Select content by the central economic argument, purpose and scope. Preserve the meaning of retained claims and the requested format. Delete excluded propositions and the sentences or paragraphs that express them. Preserve the accurate quantities, citations, equations, measured uncertainty and inference meaning of retained claims. Make factual corrections or add evidence when the user requests that work.

### Choose support for the target artifact

Use [econ-assertive](../econ-assertive/SKILL.md) and the selected source examples to improve content selection, order and natural expression. For a whole paper, use econ-writing to establish section and paragraph roles in the integrated argument before revising sentences. For a talk or site, use its medium and existing production entry point in econ-writing.

### Compare and return the requested output

Compare the revision with the original for unintended substantive changes, then return the revised text. For a review-only request, return the requested findings.
