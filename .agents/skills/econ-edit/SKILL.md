# Revise specified text

Identify the target and requested scope. EDIT alone selects the immediately preceding answer. Preserve the meaning of retained claims and the requested format; select content for the requested scope. Judge content by the central economic argument and requested purpose. Delete unnecessary supplemental propositions with their sentences or paragraphs rather than paraphrasing them, moving them to notes or replacing them with another qualification. Keep quantities, citations and equations accurate; factual correction or enrichment follows a request for that work.

Use [econ-assertive](../econ-assertive/SKILL.md) and the selected source examples to improve information selection, order and natural expression. For a whole paper, talk or site, use econ-writing for its medium and existing production entry point.

Compare the revision with the original for unintended substantive changes, then return the revised text. For a review-only request, return the requested findings.
