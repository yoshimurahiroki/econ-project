## GAME-09 移転可能効用とShapley値

有限集合 $N$ の連合 $S$ が外部との取引条件を所与として確保できる金銭換算余剰を $v(S)$、$v(\varnothing)=0$ とする。余剰を連合内で移転できるとき、主体 $i$ のShapley値は

$$\phi_i(v)=\sum_{S\subseteq N\setminus\{i\}}\frac{|S|!(n-|S|-1)!}{n!}\,[v(S\cup\{i\})-v(S)]$$

である。係数はランダムな参加順序で $i$ より前にいる主体がちょうど $S$ となる確率であり、各順序で限界貢献を足すと $v(N)$ に望遠和で一致する。対称性、寄与しない主体へのゼロ配分、ゲーム間の加法性、全余剰の配分がこの値を特徴づける。提携による離脱を防ぐには、GAME-05のコア条件 $\sum_{i\in S}\phi_i\ge v(S)$ を全連合で別途確認する。

三者の単独価値が0、$v(12)=4,v(13)=v(23)=2,v(123)=6$ のとき、限界貢献の平均は $(7/3,7/3,4/3)$、合計6である。二者連合への余剰は順に $2/3,5/3,5/3$ だけ各連合の価値を上回り、この配分はコアに入る。GAME-05の多数決ゲームではShapley値は各 $1/3$ だが、どの二者も合計 $2/3<1$ なのでコアは空である。共同研究の費用や合併余剰を評価するとき、各部分連合の外部選択を固定し、Shapley配分と離脱条件を同じ価値表で比較する。[research_numerics.py](https://github.com/yoshimurahiroki/econ-project-mini/blob/main/skills/econ-data/scripts/research_numerics.py) の `tu_shapley_core` は連合をビット集合で受け取り、有理数として配分・全余剰残差・各連合のコア余剰を返す。
