# Economics profile task

## Authority and application

Work on a custom profile only when the user requests its creation, revision or learning. An explanation or literature-research request involving a paper does not request style learning. Ordinary drafting remains under [econ-assertive](../econ-assertive/SKILL.md), with [default-micro](../econ-assertive/references/default-micro.md) as the installed reference. Making a custom profile does not itself activate it. A request to make and use one activates it for that task. A current-task choice overrides an explicitly stored project choice; otherwise select default-micro. The presence of a custom file is insufficient. Task-specific choices end with the task, and a request for the default takes effect immediately. Creating a profile does not alter persistent selection.

Read the chosen profile before applying it; retrieve the file if it is missing. If retrieval is not possible, ask for the file. Reuse the profile after reading it once. For any function it lacks, use the matching default example. Carry expression choices into the current research without substituting source-study facts, assumptions or institutional circumstances. Preserve the target facts and numbers, comparisons, notation, citations, authorship and requested genre. A change of language or section must respect the requested structure. The active research module remains responsible for substance; use the existing writing pass. Inherit the zero-default treatment of hedges, concessions, qualifications, rhetorical contrasts and emphasis from econ-assertive; discard incompatible source rhetoric.

## Requested deliverable

Return the requested profile or revision. A profile is one Markdown document identifying its name, language and scope, the exact source editions and URLs/pages, a few original paragraph adaptations, and directions for applying them. Identify examples as adaptations and use the requested language or languages, including English and Japanese when requested. Source-study facts belong only in examples about that source study. For examples about the target, use its supplied evidence or explicitly marked placeholders. Respect quotation limits and avoid reproducing distinctive source prose. Do not add scores, a separate diagnosis, an audit report, an installer or a second editing pass.

Save only when asked. Use the requested path; for a requested repository save with no path, first read `docs/ai/custom-style.md`, then update that file. A revision updates the existing profile. Preserve the installed default. Never put original PDFs or private excerpts in a public repository.

## Evidence for expression choices

Start from the requested papers, target section, language and scope. Obtain the exact files through an available Project-file tool or connector. Inspect complete relevant sections and the passages that justify each selected expression choice; use page images when extraction is garbled. Abstracts alone and imagined passages are insufficient. When reference selection is requested, choose a small relevant empirical-micro set from the available collection and primary sources.

Identify how each paragraph advances the argument and relates evidence to claims. Examine syntax, register, literal verbs and authorial voice, literature relationships and presentation of results. Keep only choices useful for the requested section. Resolve disagreements among the examples using that section's purpose and the user's preferences. All expression choices remain subject to econ-assertive.
