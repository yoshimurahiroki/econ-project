# Econ AI Resources

Lightweight index for economics-specific AI tooling and research-assistant
workflows.

## Use For

- Discovering AI tools, datasets, courses, and workflows for economists.
- Selecting research-assistant workflows for economics tasks.
- Planning reproducible AI-assisted research workflows without adding always-on
  services.

## Reference loading

Open `docs/ai/resources.md` and select one reference relevant to the current
tool, dataset, course, or workflow question. Load additional material only
when the current task requires it.

## Boundaries

- Prefer project-native tools and reproducible workflows over adding a new
  always-on service.
- Use `causal-inference-resources` for method identification questions.
- Use `econ-writing` or `econ-research-feedback` for manuscript text or critique.
