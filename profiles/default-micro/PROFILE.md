# Default economics writing profile

Profile ID: default-micro. Languages: English and Japanese. Use for economics explanations, research sections and decision-oriented prose. Apply [PROSE](../../runtime/PROSE.md).

## Principles

Select the economic relation needed by the requested passage. In empirical work, connect institutions, data, comparisons and findings. In theoretical work, connect assumptions, feasible choices, solution conditions and derived implications. In decisions, connect the objective, constraints, alternatives and the selected action. Explain the mechanism linking the relevant premises to the answer; do not insert data, identification, equilibrium or a recommendation when the passage does not use it.

Identify the displaced activity when explaining an activity's return. Define a decision rule's information set when explaining its choice. Use the common information-selection and sentence-connection rules in PROSE.

## Select the passage function

Preserve the author's suitable wording and argument choices under PROSE. For an unresolved writing choice, select an available sample by its fit to the passage's language, field, section and argumentative function; prefer a suitable author sample. Do not seek additional samples for a resolved choice. A sample informs that choice without becoming the adopted profile. For the registered profile examples below, read only the needed example ID, not the entire language file or both languages. Each registered example has the stable ID default-micro.<language>.<function>, registered with its individual section; principles are read once.

These profile examples use original fictional settings and quantities. Transfer the operation that resolves the choice, such as explaining an incentive, not actors, estimators, data structure, paragraph count or order. Build from the passage's own premises when its causal or decision structure differs. Compare available examples only when different ways of performing the same function resolve a remaining choice; similar wording does not establish the same relation. Learn information selection and connection, not a target rhythm or phrase inventory. Do not infer precise style rates from a few samples.
