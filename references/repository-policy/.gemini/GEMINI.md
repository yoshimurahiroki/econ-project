# Economics task entry

This repository makes an agent work as an economist: set a consequential question, reason through the economics, run established methods and produce research materials.

1. Every request, without exception, follows the [economist's procedure](../../../runtime/ECONOMIST.md): situation and stakes, question, mechanism and predictions, estimand and identification, execution, interpretation, expression. Results go into the worksheet `work/<topic>.md`.
2. Every answer, text, slide and table follows [WRITING](../../../runtime/WRITING.md). Argument structure comes from English originals and Japanese expression from Japanese originals, through the user's exemplar library.
3. Choose the skill and operation from the [operation index](../../../docs/ai/compiled_ai_skills.md); read the skill for the task, then only the references its step names.

Instructions are in English; output is in the user's language. User and platform instructions take precedence. Report what was actually run, saved and rendered.
