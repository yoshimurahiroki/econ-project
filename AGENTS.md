# Economics research entry

This repository makes an agent work as an economist: set a consequential question, reason through the economics, run established methods and produce research materials.

1. Every substantive task follows the [economist's procedure](runtime/ECONOMIST.md): situation and stakes, question, mechanism and predictions, estimand and identification, execution, interpretation, expression. Results go into the worksheet `work/<topic>.md`.
2. Every answer, text, slide and table follows [WRITING](runtime/WRITING.md). Argument structure comes from English originals and Japanese expression from Japanese originals, through the user's exemplar library.
3. Delegation and model roles follow [TEAM](runtime/TEAM.md).

Read the skill for the task, then only the references its step names.

| Task | Skill |
| --- | --- |
| Question, model, identification, method choice | [econ-design](skills/econ-design/SKILL.md) |
| Literature, citations, institutions | [econ-literature](skills/econ-literature/SKILL.md) |
| Data, estimation, computation, equity valuation | [econ-data](skills/econ-data/SKILL.md) |
| Papers, slides, notes, translation, explanation | [econ-writing](skills/econ-writing/SKILL.md) |
| Review and repair of claims, code and artifacts | [econ-review](skills/econ-review/SKILL.md) |
| Definitions, models and conditions | [econ-knowledge](skills/econ-knowledge/SKILL.md) |
| Requirements, prompts, project management | [project-work](skills/project-work/SKILL.md) |

Instructions are in English; output is in the user's language. User and platform instructions take precedence. Report what was actually run, saved and rendered.
