# Economic literature

## Purpose and input

Resolve the requested literature, novelty, citation or institutional-source question from supplied materials and existing holdings.

## Procedure

### Find the work that answers the comparison

Apply [DECIDE's source procedure](../../runtime/DECIDE.md#investigate-source-claims). Select papers by the unresolved mechanism, parameter or competing prediction they can establish. Distinguish a definition, documented event, causal contrast and population frequency; a case establishes occurrence, while prevalence requires its sampling frame and denominator. Use econ-writing:explain for a paper explanation.

### Establish the supporting passages and versions

Read the actual edition's determining model, design, result and contrary passages. For an assigned paper, activate `paper_reading` and its empirical, theory or structural [reading procedure](references/paper-reading.md). Preserve bibliography and PDFs, keep derived notes separate and render citations in the requested format.

### Deliver the literature's economic relevance

Return the source answer or contribution comparison with original passage locations and versions. Identify any determining unread passage and the next accessible route in task communication.

## Select the source operation

Registry conditions select the owning [literature method](references/literature-methods.md): search and ranking, novelty, replication, numerical implementation, citation/date checks, interviews or AI-method assessment. [Search priority](references/search-priority.md) owns journal ordering; its data file remains machine input.

## Source and data discovery

Activate `research_source_discovery` for the [existing corpus](references/source-discovery.md): citation traversal, multi-query retrieval, verified original passages and selected attributed propositions. Search local CSL-JSON/PDF/text holdings first. Keep bibliography-only entries visibly body-missing, extracted text distinct from inspected ranges, and each supplied reading declaration bound to its edition. Match hashes to reuse page text; keep project holdings outside the plugin.

Use `research_data_discovery` for [dataset documentation and tables](../econ-data/references/research-data.md), and `research_adaptive_experiments` for [source-grounded proposals](../econ-design/references/adaptive-research.md). Pass source identity, observation unit, measures, period and join keys to the design/data owner. A changed source or interpretation updates affected uses through their existing owners.
