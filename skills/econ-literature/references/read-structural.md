# Structural paper checklist

Use with the [paper-reading sheet](paper-reading.md).

```
Model:                 agents, information, timing, normalization, equilibrium conditions
Identification:        the variation or moments that pin down each parameter
Estimation:            likelihood, moments or objective; estimated, calibrated and fixed parameters
Numerical solution:    solver, integration, restrictions, equilibrium selection (appendix if needed)
Fit:                   baseline predictions against data
Counterfactuals:       each intervention with the primitives held fixed, the changed equilibrium, population, units, horizon
Welfare:               value function and aggregation, by scenario
Implementation:        function, version and inputs needed to recompute (for econ-data)
Answer to the question and advance over the literature:
```
