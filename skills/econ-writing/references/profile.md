# Profile economics prose

## Profile

1. A profile states form conventions shared by many originals: notation, numbers, headings, section order, tables, figures, slide layout. Sentences of an output come from exemplars at writing time, through [WRITING](../../../runtime/WRITING.md).
2. Derive each convention from several originals in the user's exemplar library and save it in `profiles/`. Source texts, excerpts and reading notes stay in the library and the user's private notes.
