# Compose economics prose

## Compose

1. **Output: selected argument; consumer: draft.** Read `python scripts/route_registry.py read prose.common-output --format compact` from the runtime root. Use PROSE's question → mechanism/comparison → evidence → answer spine. Select results changing the mechanism, action ranking, allocation or economic magnitude; retain all scientific conditions and diagnostics in the source record. Recover the tested contrast or optimizing objective through [paper guidance](paper-workflow.md#compose-the-requested-section). Before: “List the significant coefficients.” After: “Use the adopted policy contrast and interval to explain firms' employment response.”
2. **Output: result-bound draft; consumer: artifact.** Retrieve quantities, definitions and source identities through existing code. Generate numerical text, tables and figures from the same saved result. The [research renderer](../../../harness/research.md) binds semantic keys, units and formats to producing input, definition, code and execution versions. Develop complete sentences through the [paragraph's evidence and inference](paragraph-workflow.md#compose-the-paragraph), retaining source correspondence. Use [selected saved evidence](paragraph-workflow.md#command-entry-points) for inference consuming additional results. Build the explanation before compressing an Abstract, slide or summary; whole papers use paper guidance for architecture.
3. **Output: requested correspondence or revision; consumer: evidence review/response.** When requested, use the [evidence binder](../../../harness/research_evidence.py) on the selected manuscript: passages → original spans; statistics → result keys/units; equations/symbols → code, construction/calibration and residuals. Retain source quantities, assumptions, years and owner judgments with exact identities. Requested claim coverage/referee revision uses the [evidence contract](result-artifacts.md#claims-coverage-and-requested-re-review) and [manuscript-to-response sequence](paper-workflow.md#appendix-submission-and-referee-response): revise passages, assess current evidence, then write the response. Preserve earlier versions and reuse unchanged judgments/calculations.
4. **Output: inspected final artifact; consumer: delivery.** Apply PROSE's finish procedure to the assembled artifact. A changed estimate or defining assumption updates affected numerical text and argument; a display-label change rebuilds displays from the saved calculation. Keep execution links in the existing result record and deliver the supported economic argument.
