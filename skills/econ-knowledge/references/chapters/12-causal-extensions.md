# 12　因果推論の拡張：政策限界、異質性、干渉、分布

前提はCAUSALとECONである。政策が変える参加限界と曝露を定義し、母集団の効果から実行する政策の価値を構成する。

<a id="advcausal-01"></a>

## ADVCAUSAL-01　直交スコアとcross-fitting

非交絡性によるATEのスコアを

\[
\psi=m_1(X)-m_0(X)+
\frac{D[Y-m_1(X)]}{e(X)}
-\frac{(1-D)[Y-m_0(X)]}{1-e(X)}-\tau
\]

とする。真の補助関数で \(E[\psi]=0\) となり、補助関数の局所摂動に対する期待スコアの一階微分も0となる。推定誤差が積として入るため、結果回帰と傾向スコアに柔軟な学習器を使える。標本をfoldへ分け、各foldを他foldで学習した補助関数で採点する。集落標本は集落全体を同じfoldに置く。

部分線形モデル \(Y=\theta D+g(X)+u\)、\(E[u|D,X]=0\) の係数は \((D-m(X))[Y-\ell(X)-\theta(D-m(X))]\) の平均を0として推定する。\(\ell=E[Y|X]\)、\(m=E[D|X]\) であり、係数の識別には \(E[(D-m(X))^2]>0\) が必要である。一定の条件付き効果というモデルと因果解釈を支える交絡条件を区別する。

学習標本を固定して \(\delta_\ell=\hat\ell-\ell\)、\(\delta_m=\hat m-m\) と書くと、真の \(\theta\) での上のスコアの条件付き期待値は \(E[\delta_m\delta_\ell-\theta\delta_m^2]\) である。直交性は一次の誤差項を消し、残差項は二つの誤差の積と処置回帰の誤差の二乗で決まる。漸近線形表現には、この残差項が \(n^{-1/2}\) より速く小さくなる収束速度を置く。

この条件付き期待値の導出では、補助関数の学習標本と評価標本の独立性を使っている。欠測補完、標準化、変数選択、ハイパーパラメータ調整を外側foldの学習側で完結させ、その変換と学習済み補助関数を評価側へ適用する。調整に内側の交差検証を使う場合も、独立な標本単位で学習側と検証側を分け、各内側分割の変換と学習をその学習側で行う。

研修の平均効果を対象にするなら、二値処置のATEスコアで結果回帰と処置確率を学習し、対象人口の各人に同じ重みを置く。部分線形スコアの共通係数は一定効果モデルに対応する。処置効果が \(\tau(X)\) と異なる場合、二値処置と条件付き非交絡性の下でその係数は \(E[e(X)\{1-e(X)\}\tau(X)]/E[e(X)\{1-e(X)\}]\) となり、処置の条件付き分散が大きい人に重みを置く。人口ATEを求めるには最初のATEスコアを選ぶ。検索語は「double machine learning interactive regression ATE」「partially linear overlap weighted effect」「cross fitting clustered data」である。econ-designで対象と交絡条件を定め、econ-dataで独立な割当単位を保つfoldと対象スコアを設定する。

人口の半数ずつについて \((e,\tau)=(0.2,1),(0.5,3)\) なら、人口ATEは2である。部分線形係数は \((0.16\times1+0.25\times3)/(0.16+0.25)=91/41\) となる。同じ学習器を使ってもスコアの重みが変われば、同じデータから異なる母集団対象を得る。

DoubleMLでは、対象と補助回帰を次のように対応させる。表のIRMは観測ごとの重みを1とする通常のATE・ATTを扱う。

| 対象とAPI | 学習する関数とスコア |
| --- | --- |
| 部分線形係数：`DoubleMLPLR(data, ml_l, ml_m, score="partialling out")` | `ml_l`で \(\ell(X)=E[Y\mid X]\)、`ml_m`で \(m(X)=E[D\mid X]\) を学習し、上の残差化スコアを使う。 |
| 部分線形係数：`DoubleMLPLR(data, ml_l, ml_m, ml_g=..., score="IV-type")` | 予備的な残差化推定値 \(\tilde\theta\) から \(Y-\tilde\theta D\) を作り、`ml_g`で \(g(X)=E[Y-\theta D\mid X]\) を学習する。スコアは \((D-m(X))[Y-\theta D-g(X)]\)。 |
| 人口ATE：`DoubleMLIRM(data, ml_g, ml_m, score="ATE")` | `ml_g`を処置群と対照群で別々に学習して \(m_1,m_0\) を得る。`ml_m`は \(e(X)\) を学習する分類器であり、`predict_proba()`を使う。冒頭のATEスコアを評価する。 |
| 処置群ATT：`DoubleMLIRM(data, ml_g, ml_m, score="ATTE")` | 平均の対象を \(D=1\) に置き、処置群比率 \(p=P(D=1)\) と \(e(X)\) で重みを構成する。 |

結果が二値のとき、この固定版の `DoubleMLPLR` は `score="IV-type"` を指定するとエラーを返す。条件付き平均に一定の加法効果を置く線形確率モデルには `score="partialling out"` を使う。二値処置の効果が属性で異なるとき、人口平均の確率差を求めるにはIRMの `score="ATE"`、処置群での平均確率差を求めるには `score="ATTE"` を指定する。

`IV-type`はPLR内で残差化処置 \(D-m(X)\) を使うスコアの名前である。外生操作変数 \(Z\) による識別には、ECON-02の排除制約・直交条件と対応するPLIVを選ぶ。IRMの`ml_g`は処置別結果回帰、PLRの`ml_g`は構造式から処置項を引いた回帰なので、同じ引数名を各モデルの定義へ対応させる。通常のATTEスコアは

\[
\psi_{ATT}
=\frac{D}{p}[Y-m_0(X)-\tau]
-\frac{(1-D)e(X)}{p[1-e(X)]}[Y-m_0(X)]
\]

となり、未処置結果の回帰で処置群の反実仮想を構成する。データオブジェクトに結果・処置・処置前共変量を指定し、採用した割当単位で学習用と評価用のfoldを分けてから`fit()`を実行する。結果とともに対象スコア、学習器、fold、処置確率の処理、対象人口を保存する。これらの対応はDoubleMLのcommit `69c79a153f858a4e5823162793da4cabe131ea9a` にある [`DoubleMLPLR._nuisance_est`と`_score_elements`](https://github.com/DoubleML/doubleml-for-py/blob/69c79a153f858a4e5823162793da4cabe131ea9a/doubleml/plm/plr.py)、[`DoubleMLIRM._score_elements`と`_get_weights`](https://github.com/DoubleML/doubleml-for-py/blob/69c79a153f858a4e5823162793da4cabe131ea9a/doubleml/irm/irm.py) に接続する。

処置下平均について、共変量を固定して真の \(e=0.5,m_1=2\)、推定値を \(\hat e=0.4,\hat m_1=3\) とする。学習標本と独立な評価標本での補正項の期待値は \(3+(0.5/0.4)(2-3)=1.75\)。\(\hat e\) または \(\hat m_1\) の一方を真値に戻せば2になる。両方の誤差による残差が、この例のバイアス \(-0.25\) を生む。漸近正規区間は、重なり、スコアの適切なモーメント、補助推定誤差の積が \(n^{-1/2}\) より速く小さくなる収束速度の下で構成する。fold外スコアの分散は独立単位またはクラスター単位で評価する。

固定版のIRMは、各fold外の処置確率の予測を[処置確率の処理関数](https://github.com/DoubleML/doubleml-for-py/blob/69c79a153f858a4e5823162793da4cabe131ea9a/doubleml/utils/propensity_score_processing.py)へ渡す。既定では観測をすべて残し、$.01$ 未満の予測を $.01$、$.99$ を超える予測を $.99$ に置き換えてスコアを計算する。ある属性の真の処置確率が $.005$、真の処置下平均が2、結果回帰の予測が3なら、処置確率を正しく予測しても、既定の処理後の補正を含む処置下平均は $3+(.005/.01)(2-3)=2.5$ となる。結果回帰を正しく指定すれば2に戻る。二重頑健性の条件は、スコアに入れた処置確率と結果回帰に照らして判定する。重なりのある人に対象を限る研究では、その集団を定義して平均の重みを定める。

補助学習の調整経路は、DoubleMLのcommit `5c2842315724f0c70596cfc90ed13414c646e3b9` の [`tune()` と `tune_ml_models()`](https://github.com/DoubleML/doubleml-for-py/blob/5c2842315724f0c70596cfc90ed13414c646e3b9/doubleml/double_ml.py)で確認できる。互換APIの `tune()` は、既定の `tune_on_folds=False` ではデータオブジェクト全体で調整し、`tune_on_folds=True` では外側foldの学習側ごとに調整する。Optunaを使う `tune_ml_models()` もデータオブジェクト全体で調整する。上の条件付き導出に対応させる手順では、前処理・調整を含めて外側foldの学習側から補助関数を決め、評価側の情報をその選択へ入れない。

同じcommitの [`_dml_tune()`](https://github.com/DoubleML/doubleml-for-py/blob/5c2842315724f0c70596cfc90ed13414c646e3b9/doubleml/utils/_estimation.py)は、渡された学習観測に通常の `KFold` を適用する。クラスター標本では、外側学習標本の中でクラスター単位の内側分割を組み、前処理と調整を行う。その結果をfoldごとの補助学習パラメータとして渡すか、外側学習標本で再学習して評価側の補助予測を作り、対応するfoldのスコアへ渡す。

クラスター標本の外側分割には、同じcommitの [`DoubleMLData(..., cluster_cols=...)`](https://github.com/DoubleML/doubleml-for-py/blob/5c2842315724f0c70596cfc90ed13414c646e3b9/doubleml/data/base_data.py)でクラスター変数を指定する。[二方向クラスターの分割実装](https://github.com/DoubleML/doubleml-for-py/blob/5c2842315724f0c70596cfc90ed13414c646e3b9/doubleml/utils/resampling.py)は、各方向のクラスターを \(K\) 組に分け、選んだ2組の交差にある観測を評価側、両方向とも残りの組に属する観測を学習側にする。全 \(K^2\) 組合せでこの操作を行うため、各分割の学習側は評価側とどちらの方向のクラスターも共有しない。

**二重選択による部分線形回帰。** 処置 \(D\) の係数を推定する。まず対象効果と処置前の調整候補 \(X\) を研究設計で定める。基本形は \(Y=\theta_0 D+g(X)+u\)、\(E[u\mid D,X]=0\)、\(D=m(X)+v\)、\(E[v\mid X]=0\)、\(E[v^2]>0\)。処置後に決まる媒介変数やコライダーを選択候補に足すと、選択の予測精度が良くても識別対象が変わる。変数選択だけで条件付き外生性を確立することはできない。

高次元の処置前辞書 \(P(X)\) で結果回帰 \(E[Y\mid X]\) と処置回帰 \(E[D\mid X]\) を少数の項で近似できるとする。post-double-selection（一例は二重Lasso）は、① \(Y\) を辞書に回帰して集合 \(S_Y\) を選ぶ、② 同じ辞書で \(D\) を回帰して \(S_D\) を選ぶ、③ \(S_Y\cup S_D\) と設計上必須の統制を保持し、\(Y\) を \(D\) とその統制に**罰則なしで再回帰する**、の順である。二つの集合の共通部分ではない。処置の残差が正の分散を持つことと、選択後の回帰の階数を確認する。最終係数は統制を取り除いた \(D\) と \(Y\) の内積を、残差化した \(D\) の二乗和で割った値である。

仕組みは省略変数の式から分かる。例えば真の式に \(\gamma Z\) が残り、選んだ統制に対する残差をチルダで書くと、誤差が直交する場合、\(Z\) を落とした処置係数のずれは \(\gamma\,\mathrm{Cov}(\widetilde D,\widetilde Z)/\mathrm{Var}(\widetilde D)\)。結果側で見落とした変数も、処置を強く予測すればこの積を大きくする。例えば処置方程式を \(D=Z+v\)、結果方程式を \(Y=2D+Z+u\) とし、\(Z,v,u\) が互いに独立、平均0、分散1なら、\(Z\) を落とした係数は2.5、\(Z\) を保持した係数は2である。

二重選択には線形辞書による近似疎性、選択を支える設計・罰則、処置の残存変動が必要となる。最終回帰の推論に採取単位と誤差構造を反映する。係数が得られたことだけで高次元の推論条件を満たしたとは判断しない。柔軟な学習器で結果と処置を残差化し、別標本で直交スコアを評価するcross-fittingは、選択された変数の和集合で再回帰する手続きとは別に実装する。

## ADVCAUSAL-02　異質効果と政策価値

条件付き平均効果は \(\tau(x)=E[Y(1)-Y(0)|X=x]\) である。森林法は局所的な処置比較を学び、honestyは分割を決める標本と効果を求める標本を分ける。

\(\tau(x)\) は同じ観測属性を持つ人々の平均であり、各人について同時には観測できない二つの潜在結果の差を個別に復元した値ではない。効果予測の順位を使って群を作る場合、順位付けを学んだ標本とは別の標本で群平均とその不確実性を評価する。

処置確率 \(\pi(x)\in[0,1]\)、費用 \(c(x)\) の政策価値は \(V(\pi)=E[Y(0)+\pi(X)\{\tau(X)-c(X)\}]\) であり、決定的な規則は \(\pi(x)\in\{0,1\}\) の場合である。人数制約 \(E[\pi(X)]\le q\) の下で無作為化を許すと、正の純効果を持つ人から効果の大きい順に処置し、容量が余っていても負の純効果の人には処置しない。容量の影価格 \(\lambda\ge0\) は \(\lambda\{q-E[\pi(X)]\}=0\) を満たし、純効果が \(\lambda\) より大きければ処置、小さければ非処置とする。等しい集団の一部を選ぶ必要があれば、その集団を確率的に配分できる。決定的な規則だけを許し、同じ属性の集団を分割できない場合は、この閾値配分が実行可能とは限らず、許容される規則の中で別に最適化する。政策学習と評価に異なる標本を用い、評価標本で対応する二重頑健価値を計算する。

外部集団への輸送は、共変量を条件とする効果の共通性と支持の重なりを置き、外部集団の共変量分布で効果を積分する。grfは局所効果とその集約の候補となる。

就業支援の対象を選ぶとき、\(Y\) を金銭換算した便益で測り、同じ期間・通貨単位の費用を差し引いて既存の一律配分と比較する。政策の実務上の規則が年齢と所得の閾値に限られるなら、その実行可能な規則集合で価値を最大化し、独立した評価標本で一律配分との差と割当単位の区間を求める。訓練標本で推定した高効果群の効果と、固定された規則の評価標本での価値はそれぞれの対象人口で計算する。「causal forest treatment heterogeneity」「policy learning capacity constraint」「off-policy evaluation」を検索し、econ-designで費用・対象・実行可能な規則を定める。

例えば人口の40%が効果5、残り60%が効果2で、共通費用1、容量が人口の40%なら、高効果群を処置する純便益の人口平均増分は \(0.4(5-1)=1.6\)。高効果群の純効果4、他群の純効果1なので、容量を少し減らす限界損失は4、少し増やす限界便益は1となる。境界に集団全体が並ぶこの例では容量制約の影価格は1から4の範囲であり、単一値を強制しない。候補規則を学習した後、その固定された規則の価値差と不確実性を独立評価標本で計算する。

## ADVCAUSAL-03　MTEと政策拡張

\(D=1\{U\le p(Z,X)\}\)、\(U|X\sim U[0,1]\) とする。\(U\) は処置への抵抗の順位である。\((Y(0),Y(1),U)\perp Z\mid X\) と除外制約を置くと、連続な条件付き \(p\) の支持の内部で、適切な微分可能性の下、\(\partial E[Y|p,X]/\partial p=MTE(p,X)\) を得る。ここで \(MTE(u,X)=E[Y(1)-Y(0)|U=u,X]\) である。単一の潜在順位に従って参加が変わるという選択構造も、この局所比較の前提となる。

政策が参加確率を \(p_0(x)\) から \(p_1(x)\) へ変えるとき、人口平均結果の増分は

\[
E_X\left[\int_{p_0(X)}^{p_1(X)}MTE(u,X)\,du\right].
\]

歴史的IVが動かす参加限界と新政策が動かす区間を対応させる。有限変化には区間全体の積分を使う。

例えば \(MTE(u)=4-2u\) なら、一定の \(X\) で観測条件付き平均は \(E[Y|p]=a+4p-p^2\) と表され、その傾きがMTEに一致する。参加確率を0.2から0.5に上げる人口平均効果は \([4p-p^2]_{0.2}^{0.5}=0.99\)、新規参加者平均は \(0.99/0.3=3.3\)。識別にはこの区間全体で政策対象の \(p\) が操作変数の条件付き支持に含まれることが必要で、支持が0.3から0.5だけなら0.2から0.3を仮定なしに埋められない。

授業料補助で進学率を0.2から0.5に変える政策では、その区間のMTE積分が求める人口平均効果となる。既存の二値IVが動かした区間が同じなら、そのLATEに参加率の変化0.3を掛けて同じ人口平均効果を得る。異なる区間を動かす政策では、各区間の効果の異質性と操作変数の条件付き支持を調べる。「marginal treatment effect local instrumental variables」「policy relevant treatment effect support」「treatment effect heterogeneity tuition」を検索し、学費や資格制度が結果へ直接作用する経路を資料で照合する。econ-designで政策対象と外生性・支持を定めてからecon-dataに積分と推論を渡す。

## ADVCAUSAL-04　shift-share

地域の基準期産業比率を \(s_{ik}\)、産業ショックを \(g_k\) とし \(Z_i=\sum_ks_{ik}g_k\) を作る。shock-basedの識別はショックの割当、share-basedの識別は基準期構成の直交条件に基づく。

残差化した誤差について \(\sum_iZ_iu_i=\sum_kg_k\sum_is_{ik}u_i\) と書ける。右辺はshock-levelの直交条件と推論単位を示す。共通ショックへの曝露、ショック間依存、支配的産業、当該地域を除外したショック構成を識別式へ含める。

対象産業の比率の和 \(S_i=\sum_k s_{ik}\) が地域ごとに異なり、ショックに共通の条件付き平均があると、その平均と \(S_i\) の積も操作変数を動かす。ショックに関する識別を使う場合は、条件付き平均に対応する総曝露などの統制を定め、残るショックの直交条件を検討する。基準期比率を単に古い時点で測るだけでは、構成の外生性は保証されない。

2地域・2産業で比率を \(((0.8,0.2),(0.3,0.7))\)、ショックを \((2,-1)\)、残差を \((1,-2)\) とすると、地域別 \(Z\) は \((1.4,-0.1)\) で \(\sum_iZ_iu_i=1.6\)。産業別の曝露加重残差は \((0.2,-1.2)\) で、ショックとの積和も \(2(0.2)-1(-1.2)=1.6\) となる。これは代数上の等価性であって外生性の証明ではない。多数の地域があっても独立ショックが少数なら情報量を地域数だけで判断せず、ショック依存と集中を反映して推論する。

輸入競争が地域雇用に与える効果を調べるなら、対象とする雇用の期間と地域、基準期産業構成、産業ごとの競争ショックを固定する。産業ショックの割当と他の地域労働需要変動との関係を擁護できる設計ではshock-basedの直交条件を使う。地域の産業構成自体の事前の形成過程が比較を支える設計ではshare-basedの条件を使う。共通ショックへの曝露が重なる地域を考慮し、主要ショックの寄与とショック間依存に対応して推論する。「shift share instrument shock exogeneity」「Bartik shares identification」「shift share exposure robust inference」を検索し、econ-literatureで産業構成と競争ショックの原資料を調べてecon-designに識別根拠を渡す。

## ADVCAUSAL-05　干渉と時間変動処置

\(Y_i(d_i,e_i)\)、\(e_i=f_i(D_{-i},G)\) を定義する。直接効果は曝露を固定した \(Y_i(1,e)-Y_i(0,e)\)、波及効果は自己処置を固定した \(Y_i(d,e_1)-Y_i(d,e_0)\) である。割当から各曝露の生起確率を求め、その逆数で結果を重み付けする。集落間干渉が0なら集落内処置率を無作為化する二段階設計で処置率の効果を比較できる。

この表現は、全体の割当が異なっても個人 \(i\) の自己処置と定義した曝露が同じなら、その人の潜在結果も同じという仮定を含む。曝露写像を指定しただけでは、この仮定は確認できない。割当間で結果が依存するため、不確実性には設計に基づく共同曝露確率や独立な無作為化単位を反映する。

縦断データでは過去処置が次期交絡 $L_t$ を変える。各期に $L_t$ を観測してから $D_t$ を選び、最終処置後に $Y$ を測る。履歴 $H_t=(\bar L_t,\bar D_{t-1})$ と決定的政策 $d_t^\pi(H_t)$ を定義し、政策で生じる処置履歴を $\bar d_t^\pi$ と書く。整合性と、政策に従った履歴上での逐次交換可能性
\[
(Y^\pi,\bar L_{t+1:T}^\pi)\perp D_t\mid H_t,\quad
\bar D_{t-1}=\bar d_{t-1}^\pi
\]
を置く。政策が到達する履歴で $P(D_t=d_t^\pi(H_t)\mid H_t)>0$ も成立すると、政策下の平均結果は
\[
E[Y^\pi]=\int E[Y\mid\bar L_T=\bar l_T,\bar D_T=\bar d_T^\pi]
\prod_{t=0}^T f(l_t\mid\bar l_{t-1},\bar d_{t-1}^\pi)\,d\bar l_T
\]
である。共変量遷移と最終結果の条件付き平均を推定し、政策に沿って順に積分する。重みを用いる場合は $p_t(d\mid H_t)=P(D_t=d\mid H_t)$ として、$W_i^\pi=\prod_{t=0}^T1\{D_{it}=d_t^\pi(H_{it})\}/p_t(d_t^\pi(H_{it})\mid H_{it})$ を構成し、$E[W^\pi Y]$ を計算する。政策が移住やリンクを変える場合は、その遷移も履歴と政策の結果に含める。

2人組で互いの処置のみが曝露を決め、各人を独立に確率1/2で処置するなら、自身と相手がともに処置される確率は1/4である。この曝露条件に該当する観測結果の逆確率寄与は \(4Y_i\) となる。曝露確率が0の条件の効果はこの設計では推定できない。別の2期政策で、初期処置後の \(P(L_1=1)=0.3\)、規則に従った最終結果の条件付き平均が \(L_1=0\) で2、\(L_1=1\) で6なら、政策下平均は \(0.7(2)+0.3(6)=3.2\)。この遷移分布は観測された全員の無条件分布でなく、その政策に沿う初期処置の下で評価する。

感染予防の介入で本人への接種と周囲の接種率を変えるなら、接触関係と割当から各曝露確率を求め、同じ本人処置の下で周囲の曝露差を比較する。治療開始・中断を繰り返す追跡研究で過去の治療が将来の健康状態と治療選択を変えるなら、治療履歴を指定したg-formulaまたは履歴重みを選ぶ。両方が働く場合は、各期の曝露・関係変化を履歴に含めて政策を定義する。検索語は「interference exposure mapping randomized design」「time varying confounding longitudinal g formula」「treatment history positivity」であり、econ-designで割当と観測順序を確定し、econ-dataでその政策下の平均を計算する。

## ADVCAUSAL-06　分布と媒介

分布効果は閾値ごとの \(P(Y(1)\le y)-P(Y(0)\le y)\) である。各潜在結果の周辺分布から分位点差 \(Q_{Y(1)}(\tau)-Q_{Y(0)}(\tau)\) を求める。個人別効果の分布には潜在結果間の結合分布を指定する。

媒介 \(M\) について \(Y(d,m)\) を定義する。controlled direct effectは \(m\) を固定した比較、個人のnatural direct effectは \(Y(1,M(0))-Y(0,M(0))\)、その母集団平均である平均自然直接効果は \(E[Y(1,M(0))-Y(0,M(0))]\) となる。後者の識別には処置と媒介の割当、処置後交絡、反実仮想の結合を支える条件を置く。実施可能な媒介分布介入は、その分布を置き換えたg-formulaで評価する。

処置前共変量を \(C\)、観測された条件付き平均を \(\mu(d,m,c)=E[Y\mid D=d,M=m,C=c]\) とする。整合性、必要な正値性、処置・媒介に関する適切な条件付き交換可能性とcross-world独立性を置き、処置に影響された媒介–結果交絡がない標準的な場合、離散 \(M,C\) について平均自然直接効果は
\[
\sum_{c,m}\{\mu(1,m,c)-\mu(0,m,c)\}P(M=m\mid D=0,C=c)P(C=c)
\]
で識別される。自然間接効果も同じ交絡と結合の仮定に依存する。処置を無作為化しても媒介–結果関係の交絡は自動的には消えず、処置後の交絡を通常の回帰で調整するだけではこの自然効果を一般に識別できない。媒介分布を介入で変える別の効果を使う場合は、どの集団の分布をどう割り当てるかとその識別条件を新たに定義する。

両処置状態の周辺分布がともに確率1/2のBernoulliでも、\(Y(1)=Y(0)\) と結合すれば個人効果は全員0、\(Y(1)=1-Y(0)\) と結合すれば個人効果は半数が1、半数が−1である。周辺分布だけでは二つを区別できない。媒介の別例として \(Y(d,m)=d+2m\)、\(P(M(0)=1)=0.25\)、\(P(M(1)=1)=0.75\) なら、平均自然直接効果は1、処置下の平均自然間接効果は \(2(0.75-0.25)=1\)、平均総効果は2となる。これらの反実仮想を観測から回収するには、媒介と結果の交絡やcross-world条件について別途仮定が必要である。

授業料補助が就業所得の分布へ及ぼす影響を調べるなら、処置の条件付き交換可能性と重なりの下で、処置別の所得分布や各分位点を対象人口で比較する。個人ごとの所得変化の分布を求めるときは、二つの潜在所得の結合に追加の構造を置く。進学を経由する経路を研究するなら、同じ進学水準に固定するcontrolled direct effect、無処置時の進学を使う平均自然直接効果、実施する進学分布介入の効果のどれが政策に対応するかを決める。処置後の媒介・結果交絡を測った場合はその遷移を含む介入対象と識別条件を定める。「distributional treatment effects marginal distributions」「natural direct effect cross world」「interventional indirect effects exposure induced confounding」を検索し、econ-designで実施可能な介入と交絡構造を定める。

## ADVCAUSAL-07　識別集合

二値結果で \(p=P(D=1)\)、\(\mu_d=E[Y|D=d]\) のみを観測すると、ATEの下界は \(p\mu_1-(1-p)\mu_0-p\)、上界は \(p\mu_1+(1-p)-(1-p)\mu_0\) となる。未観測反実仮想の平均を0と1へ置いて導く。単調応答などの制約はこの集合へ交差させる。

モーメント不等式の集合は \(\Theta_I=\{\theta:E[g_j(W,\theta)]\ge0,\ \forall j\}\) である。反実仮想集合は \(\{T(\theta):\theta\in\Theta_I\}\) とし、同じパラメータがすべての制約を同時に満たす。感度分析は、未処置トレンド差や交絡の強さを数量で置き、結論を変える値を求める。

未測定交絡によるずれを観測済み共変量の調整前後の差で較正する場合、その差が未測定部分の影響をどの程度代表するかは追加仮定である。較正値を変えた識別集合や政策順位を報告し、較正そのものがデータから検証された事実であるかのようには扱わない。

例えば \(p=0.4,\mu_1=0.75,\mu_0=0.25\) なら、観測データと整合するATEは \([-0.25,0.75]\) である。未観測の各反実仮想平均は独立に0から1まで動かせるため、この区間内の各値は実現可能であり、両端は鋭い。全員への処置に1人当たり0.2の費用がかかり、結果1単位を便益1と評価するなら、全員に処置する政策の無処置に対する純便益は \([-0.45,0.55]\) に写る。この集合は0をまたぐので、データと仮定だけでは政策の優劣を一意に決められない。全員の処置効果が非負という追加仮定の下ではATE集合は \([0,0.75]\)、純便益集合は \([-0.2,0.55]\) で、やはり費用を考えると順位は定まらない。

政策の選択では、共通の費用を引いた純便益集合が全体として0を超えるなら処置、全体として0を下回るなら無処置を選ぶ。上のように0をまたぐ場合、意思決定基準を明示して最大最小便益や最大後悔の最小化を計算し、意思決定者が許容する基準に沿って順位を決める。条件付き交換可能性と正値性を支える設計・測定が得られれば、その追加条件の下で点識別されたATEを同じ人口・費用に写して比較する。検索語は「Manski bounds binary outcome」「moment inequality confidence region」「partial identification policy choice」であり、econ-literatureで各制約の制度的根拠と対象集団を照合し、econ-designで制約集合と政策基準を採択する。

識別集合と標本誤差も区別する。上の二値例で \(A=D(1-Y)+(1-D)Y\) と置くと、下界と上界はそれぞれ \(-E[A]\)、\(1-E[A]\) であり、独立同分布標本で \(\hat q=\bar A\) の標準誤差は \(s=\sqrt{\hat q(1-\hat q)/n}\) と推定できる。正規近似が適切な内部点では、両端を同時に覆う保守的な95%区間として \([-\hat q-1.96s,\ 1-\hat q+1.96s]\) を使える。例えば1000人中 \(A=1\) が250人なら \(s\simeq0.0137\)、区間は約 \([-0.277,0.777]\) である。これは識別集合全体を覆うための区間で、単一の真のATE向けの区間と目的が異なる。クラスター依存や境界付近では対応する分散・標本分布を使う。一般の不等式モデルでは、推定モーメントの同時誤差を考慮して候補 \(\theta\) ごとに制約を検定し、棄却されない集合を政策関数 \(T\) に写す。各不等式や政策結果の端点を別々に最適化する際も、同じ \(\theta\) の同時実行可能性を維持する。

例えば有限個の不等式で \(\bar g_j(\theta)=n^{-1}\sum_i g_j(W_i,\theta)\) とし、違反度の目的関数を \(Q_n(\theta)=\sum_j\min\{\bar g_j(\theta),0\}^2\) と置く。母集団版 \(Q\) のゼロ集合が識別集合となる。集合全体を覆う推論では、候補ごとの点ごとの臨界値を無条件に流用せず、\(\sup_{\theta\in\Theta_I}nQ_n(\theta)\) の分布に対応する臨界値を定め、\(\{\theta:nQ_n(\theta)\le c\}\) を構成する。未知の集合と臨界値を標本から近似する場合、採用する部分標本法やブートストラップの妥当性、依存に合う再標本化単位、接触する不等式の扱いを確認する。得られた外側集合を \(T\) に写すと、モデルと推論条件の下で政策結果の集合を含む外側集合となる。

## ADVCAUSAL-08　解答付き例題：動かす限界

\(MTE(u)=12-10u\) とする。参加確率を0.2から0.5へ増やす政策の人口平均効果は2.55、新規参加者割合は0.3、誘発参加者平均は8.5となる。処置費用が参加者1人6なら人口平均純便益は \(2.55-0.3\times6=0.75\) である。0.7から1.0への拡張では誘発参加者平均が3.5となり、同じ費用で人口平均純便益は \(-0.75\) となる。

両政策の費用がそれぞれ誘発参加者平均の8.5と3.5に等しい点が純便益の分岐点である。この比較をデータから識別するには、それぞれ \([0.2,0.5]\)、\([0.7,1]\) の参加限界を操作変数が動かす支持と識別仮定が必要になる。片方の区間しか観測されなければ、もう片方の数値は外挿の仮定に依存する。
