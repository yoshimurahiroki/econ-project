# 08 ネットワーク経済学

線形代数を基礎に、ゲーム、統計と因果推論を必要な項目で用いる。関係の構造が個人の選択、伝播と介入の効果をどう変えるかを扱う。

## NET-01 グラフと中心性

主体を頂点、関係を辺とするグラフを隣接行列 $G$ で表す。$G_{ij}$ は $i$ に影響する $j$ との関係の重みであり、自己辺は $G_{ii}=0$ とする。無向グラフでは $G_{ij}=G_{ji}$ とし、以下の重みは $G_{ij}\ge0$ とする。次数 $d_i=\sum_jG_{ij}$ は直接の接続の大きさである。次数行列 $D=\operatorname{diag}(d_i)$ とラプラシアン $L=D-G$ を用いると、無向グラフでは $x'Lx=\tfrac12\sum_{ij}G_{ij}(x_i-x_j)^2\ge0$ となる。これは隣接する主体の値の差の合計を測る。

固有ベクトル中心性は $Gc=\rho(G)c$ の非負固有ベクトルで、中心的な主体とつながる主体を高く評価する。非負で既約な $G$ なら正の固有ベクトルが正の倍率を除き一意であり、例えば $\sum_i c_i=1$ で規格化する。Katz 中心性 $(I-\alpha G)^{-1}\mathbf1$ は $\alpha\ge0$ と $\alpha\rho(G)<1$ の下で各長さの重み付きウォークを $\alpha$ で割り引いて足す。長さ $k$ のウォークには頂点や辺の再訪を含み、$G^k$ の各要素は重みの積をウォークごとに合計した値である。$(I-\alpha G)$ が可逆なら線形方程式の解は存在し、反復とウォーク和がその解へ収束する条件は $\alpha\rho(G)<1$ である。データには辺の方向、重み、観測時点を記録し、分析する相互作用に対応した行列を作る。

中心性の選択は調べる経済的対象で決める。直接の接触機会には次数、正の相互作用が反復する行動モデルにはNET-02で定義する係数付き乗数、閾値を超える採用にはNET-03の状態更新を使う。辺の方向、重みの単位、観測されない辺、政策後の辺の変更を調べ、「network centrality key player intervention」「exposure mapping network measurement」を検索する。政策の因果効果を求める仕事ではNET-06の割当と曝露を採択し、中心性はその設計の対象者・異質性を記述する。これにより検索候補から、行動均衡の計算と実験効果の推定のそれぞれに必要な入力を選べる。

## NET-02 線形二次ゲーム

主体 $i$ が行動 $a_i\ge0$ を選び、利得が $u_i=a_i b_i-\tfrac12a_i^2+\gamma a_i\sum_jG_{ij}a_j$ であるとする。$b_i>0$、$\gamma\ge0$、$G\ge0$ の下で最適反応は $a_i=b_i+\gamma\sum_jG_{ij}a_j$ となる。$\gamma\rho(G)<1$ なら均衡は一意で $a^*=(I-\gamma G)^{-1}b=\sum_{k\ge0}\gamma^kG^kb$ である。直接効果 $b$ と、長さ $k$ の経路を通じた反応を分けて読める。

主体 $j$ の基礎便益を一単位増やしたときの全体効果は $(I-\gamma G)^{-1}$ の第 $j$ 列の和である。同じ大きさの補助を一人に与え、行動の合計を最大化する場合、この列和が最大の主体を選ぶ。主体そのものを除去する政策では、本人の基礎便益だけでなく、その主体に接続する辺もなくなる。残ったネットワークごとに均衡を解き直すため、補助の列和が最大の主体と除去効果が最大の主体は一致するとは限らない。厚生最大化では介入費用と各主体の利得、相互作用による外部効果を合計し、均衡反応を代入して比較する。

線形二次ゲームの集計効果は逆行列から具体的に計算できる。均衡で $a^*=b+\gamma Ga^*$ を両辺微分すると、$(I-\gamma G)da=db+\gamma(dG)a^*$ である。個人への補助 $db$ は既存の辺を通じて波及し、辺の追加 $dG$ はつながる相手の現在の行動に比例する一次効果を生む。どちらも同じ逆行列を掛けることで各主体と全体への効果に変換できる。

補助による総行動の変化を観測データへ適用するには、$\gamma$ と $b$ の同定、辺を固定する政策期間、行動の下限と容量を確認する。内生的な近隣行動の係数はNET-05、割当から直接・波及効果を求める設計はNET-06を使う。「linear quadratic network game identification」「endogenous network policy counterfactual」を調べ、介入で辺が形成・切断される場合はNET-04の形成を追加する。この変更は元の逆行列、均衡行動、補助費用と厚生をすべて更新する。econ-dataには採択した行列・係数・対象者・費用を渡し、元の最適反応残差と政策後の集計を保存する。

参加者が増える便益と処理容量の混雑は、同じ利得に入れて設備と料金を選ぶ。需要量 \(Q=\sum_i a_i\)、容量 \(K\)、一単位の混雑費用 \(c(Q/K)\) を持つサービスでは、利用者は自身の便益と料金に加えこの私的費用を比較する。一単位の追加利用が全利用者へ及ぼす外部費用は、共通の貨幣尺度の下で \((Q/K)c'(Q/K)\) となる。正の接続便益がある場合はその外部便益も加えて利用の社会的限界価値を求める。利用量に反応して容量を増やすときは、混雑減少と参加・利用の増加を均衡へ戻し、利用者便益と事業者利益から設備の実物費用を引く。道路の経路選択はSPATIAL-05、両側参加と手数料はIO-05の対応する均衡を使う。

## NET-03 伝播と閾値

状態 $s_i(t)\in\{0,1\}$ が、一度採用すると維持されるモデルを考える。未採用の主体 $i$ が採用済み隣人の重み付き比率 $\sum_jG_{ij}s_j/\sum_jG_{ij}$ が閾値 $\tau_i$ 以上になったとき採用するなら、初期採用者から逐次更新して最終採用集合を計算できる。次数がゼロの未採用者は隣人からの伝播では採用しないと定める。密集した集団は内部で閾値を超えやすく、集団を結ぶ少数の辺は集団間伝播を支える。

例えば四人が $1$—$2$—$3$—$4$ の順に一列につながり、辺の重みが同じで、初期採用者が1だけとする。共通閾値が $1/2$ なら、2は採用済み隣人の比率が $1/2$ なので採用し、次に3、最後に4も採用する。閾値を $3/5$ に上げると、2の比率 $1/2$ が閾値に届かず、最初の状態で伝播が止まる。初期採用者と閾値を固定した上で、各時点の隣人数と採用済み人数を追う。

感染と回復を含む平均場モデルでは、感染確率の近似は $\dot x_i=\beta(1-x_i)\sum_jG_{ij}x_j-\mu x_i$ であり、無感染状態付近では $\dot x_i\simeq\beta\sum_jG_{ij}x_j-\mu x_i$ と線形化できる。非負の既約な $G$ では成長率が最大のモードは $\beta\rho(G)-\mu$ で、この値が正ならゼロでない非負の初期感染はその成長モードを持つ。既約でない場合は、初期感染から影響が届く部分に成長可能なモードがあるか確認する。有限人数の厳密な確率モデルでは、外部からの感染がなく $\mu>0$ なら最終的に無感染状態へ吸収されるため、この閾値は平均場の局所的な成長条件として解釈する。辺、伝播率、回復率を変える介入はこの条件を変える。

製品の普及策では、初期採用者の選定・補助費用と、伝播後の利用が生む割引貢献利益を比較する。採用閾値のモデルでは対象者への一人分の介入が複数集団の閾値を超える場合があり、最終採用者数の増加と利益の増加を候補集合ごとに計算する。ネットワークの辺、初期採用、採用時刻、利用量、紹介割当と補助支払を結び、共通の需要ショックによる同時採用をNET-05・06の設計で分離する。更新・解約を認める製品には不可逆な採用に代えて状態遷移を置き、INNOV-04の顧客利益と合わせる。利用の増加が混雑や既存顧客の離脱を生む場合は、その損失と容量制約を普及策の目的に含める。

## NET-04 ネットワーク形成

二者 $i,j$ が辺を追加するとき双方の利得が弱く増え少なくとも一方で厳密に増える組が存在せず、既存の辺を片方が単独で切って利得を増やせないネットワークをペアワイズ安定という。ここでは一方が無差別でも他方が得をすれば辺を追加すると定める。双方が厳密に得をする場合だけ追加すると定める弱い安定性では、無差別となる組の判定が異なる。利得に直接接続便益、間接到達便益、辺の費用を入れ、各辺の追加と削除を調べて安定性を確認する。

例えば $u_i=bd_i-cd_i$ だけのモデルでは $b>c$ なら全辺形成、$b<c$ なら空グラフが安定する。二次近傍からの便益や混雑を入れると、個人の接続選択が他者の到達可能性を変えるため、安定ネットワークと総余剰最大のネットワークが異なり得る。補助や接続費の変更は形成後の行動も含めて比較する。

距離 $d_{ij}$ の接続便益を $\eta^{d_{ij}}$、直接辺一本の費用を各端点に $c$ とし、未接続間の便益を0とする。三人で $\eta=1/2,c=2/5$ の星を作ると、中央の各辺の削除損は $1/2-2/5=1/10$、端点の削除損は $1/2+1/4-2/5=7/20$ である。端点間の新しい辺は各端点の便益を $1/2-1/4-2/5=-3/20$ だけ変えるので星は安定する。空グラフ、一本だけ辺を持つグラフ、星、完全グラフの四つの同型でない構造の総余剰は、それぞれ $0$、$2(1/2-2/5)=1/5$、$4(1/2-2/5)+2(1/4)=9/10$、$6(1/2-2/5)=3/5$ である。各辺の追加・削除と四構造の余剰を照合できる。

## NET-05 ピア効果と反射問題

集団 $g$ の成果を $y_{ig}=\alpha+\beta\bar y_{-i,g}+\gamma\bar x_{-i,g}+x_{ig}'\delta+\eta_g+\varepsilon_{ig}$ とする。$\beta$ は他者の成果に反応する内生的ピア効果、$\gamma$ は他者の属性から受ける文脈効果である。同じ集団に共通の環境 $\eta_g$ と同時決定により、他者の平均成果と自分の誤差は関連する。

行列形 $y=\alpha\mathbf1+\beta Gy+\gamma Gx+X\delta+\varepsilon$ では、$\rho(\beta G)<1$ のとき $y=(I-\beta G)^{-1}(\alpha\mathbf1+\gamma Gx+X\delta+\varepsilon)$ である。ネットワークの構造が $G^2x$ を $x,Gx$ と独立した変動として与え、属性が誤差から外生的で、除外制約を満たす場合、二次近傍の属性を操作変数に利用できる。行列の線形独立性は同時方程式と係数制約を使った構造識別にも関わるが、操作変数として使うには外生性と除外制約を別途確認する。同じ人数 $m$ の完全結合グループで自分を除く平均を取ると、$G=(J-I)/(m-1)$ かつ $G^2=I/(m-1)+(m-2)G/(m-1)$ となる。このとき $G^2x$ は $x,Gx$ の線形結合なので、二次近傍だけを追加しても除外された変動を作れない。属性が一つで直接効果が $\delta$ のとき、$\beta\delta+\gamma=0$ なら $(I-\beta G)^{-1}(\delta I+\gamma G)x=\delta x$ となり、属性を通じた波及は相殺される。したがって、行列のランクだけでなく、波及を生む係数の組合せ、操作変数の第一段階、近隣属性の外生性をそれぞれ検査する。辺の形成が成果と共通原因を持つ場合は、その形成過程や外生的割当を研究設計に入れる。

## NET-06 波及の因果効果

各主体の結果を $Y_i(z_i,e_i)$ とし、$z_i$ は本人への介入、$e_i$ は近隣の処置から作る曝露量とする。例えば $e_i=\sum_jG_{ij}z_j$ である。割当ベクトル $Z$ から本人の曝露 $D_i$ を決め、同じ曝露を生む割当では結果が等しいと定義する。対象とする各人の曝露確率 $\pi_i(d)=P(D_i=d)$ が正なら、有限集団平均の推定量は $\widehat\mu(d)=N^{-1}\sum_i1\{D_i=d\}Y_i/\pi_i(d)$ である。期待値を取ると各項は $Y_i(d)/N$ になり、全員の潜在結果の平均に一致する。確率が0の主体を含む平均には、この割当から対応する結果を復元できない。本人処置を固定して曝露を変えた平均差が波及効果となる。

独立なクラスターごとに処置を割り当てる設計では、クラスター数と割当方法に基づき分散を計算する。クラスターをまたぐ辺があるときは、その辺を含めて曝露を定義し、割当規則から各曝露確率を求める。介入の直接効果、隣人への波及、総効果はそれぞれの処置と曝露の組を指定して比較する。

無作為化された介入で本人処置と隣人曝露を区別するには、それぞれの組が観測可能になる割当を使う。例えば二人組の各人を独立に確率 $1/2$ で処置すると、本人処置 $z\in\{0,1\}$ と隣人処置 $e\in\{0,1\}$ の四組はそれぞれ確率 $1/4$ で現れる。$E[Y(0,1)]-E[Y(0,0)]$ は本人が未処置のとき隣人を処置する効果であり、$E[Y(1,0)]-E[Y(0,0)]$ は隣人が未処置のときの本人処置効果である。

例えば政策の対象を固定した本人処置の直接効果は $\mu(1,e)-\mu(0,e)$、本人処置を固定した波及効果は $\mu(z,e_1)-\mu(z,e_0)$ と定義する。全員への政策を評価する総効果には、その政策が作る本人処置・曝露の同時分布を使う。設計選択では各曝露の正の確率と、分散に必要な二人の同時曝露確率 $\pi_{ij}(d,d')$ を確認する。全体の処置人数を固定する割当と独立割当は、この確率と推論を変える。「randomization inference network exposure joint probabilities」「spillover saturation design」を調べ、事前に記録した辺と実際の割当規則をecon-designへ渡す。econ-dataはその規則から曝露確率と推論を計算する。新しい政策で辺や曝露写像が変わるときは、その変更と結果の対応を再定義してから総効果を評価する。

## NET-07 例題：三人の線形ゲーム

三人が一列につながり、両端は中央とだけ、中央は両端とつながる。各人の基礎便益 $b_i=1$、相互作用係数 $\gamma=1/4$ とする。対称性より両端の行動を $x$、中央を $y$ と置くと、最適反応は $x=1+y/4$、$y=1+x/2$ である。代入すると $x=10/7$、$y=12/7$ となる。隣接行列の最大固有値は $\sqrt2$ なので $\gamma\rho(G)=\sqrt2/4<1$、この均衡は一意である。中央は二人から反応を受けるため両端より行動が大きい。
