## CAUSAL-05　回帰不連続

running variableを \(R\)、閾値を \(c\)、割当を \(D=1\{R\ge c\}\) とする。潜在結果の条件付き平均が \(c\) で連続なら

\[
\tau(c)=\lim_{r\downarrow c}E[Y|R=r]
-\lim_{r\uparrow c}E[Y|R=r].
\]

左右の局所多項式を別々に当て、閾値での切片差を求める。kernelと帯域は使う局所標本を定める。高次局所推定によるバイアス補正は、その補正の標本変動も区間へ含める。fuzzy RDDでは、割当両側の潜在結果と潜在受療の条件付き平均が閾値で連続であり、閾値での受療確率の跳びがゼロでなく、割当が受療以外の経路で結果を変えず、閾値を超えることで受療をやめる個体がいないという単調性を置く。結果の跳びを処置確率の跳びで割ると、閾値で受療を変える者の局所平均効果を得る。

sharp設計で各側の条件付き平均が閾値付近で二階微分可能、閾値でのrunning variableの密度が正、独立観測と有界な条件付き分散を置く。局所線形の帯域を \(h\) とすると、先行バイアスは \(O(h^2)\)、標準誤差は \(O((nh)^{-1/2})\) である。非退化な先行バイアスと分散の下、平均二乗誤差を最小化する帯域の次数は \(n^{-1/5}\) で、バイアスと標準誤差は同じ次数になる。左右の局所二次回帰を帯域 \(b\) で当てて先行バイアス \(\widehat B\) を求め、\(b/h\) が正の有限定数へ収束する設計の補正推定量を \(\hat\tau_{bc}=\hat\tau_h-\widehat B\) とする。頑健バイアス補正区間は、両推定量とその共分散を含む \(\widehat{\operatorname{Var}}(\hat\tau_h-\widehat B)\) の平方根で学生化し、残余バイアスが標準誤差に比べて消える滑らかさと帯域の条件の下で閾値効果 \(\tau(c)\) を対象とする。推定に使う多項式次数、kernel、左右の帯域、補正用帯域と両側の観測数を記録する。

計算例では閾値を0、左右各5点のrunning variableを \(\pm(.1,.3,.5,.7,.9)\)、結果を \(Y=2+3R+2R^2+1\{R\ge0\}(5+R+R^2)\) とする。三角kernel、\(h=1.2\)、\(b=1.5\) では局所線形の切片差が4.866878、推定バイアスが−0.133122、補正後は5となり、元の左右の二次式の切片差に一致する。各点の誤差分散を1、点間の誤差を独立とした設計分散は、補正推定量の重みの二乗和から4.304169となり、補正項との共分散を含む展開式と一致する。

閾値で同時に変わる制度、スコア操作、離散採点、heapingを割当過程へ対応させる。離散スコアでは独立したスコア値の数と制度を使って比較を構成する。rdrobustとrdrandinfはそれぞれ局所多項式と局所無作為化の候補である。

閾値の直下と直上の結果の極限がそれぞれ10と13、受療確率の極限が0.2と0.8なら、割当による結果の跳びは3、fuzzy比は \(3/0.6=5\) である。後者が閾値付近で受療を変える人の効果となるには、上記の除外と単調性が必要である。受療の跳びが小さい場合は比が不安定になるため、分子と分母の推定誤差と共分散を扱い、弱い第一段階に対応する推論を検討する。連続性に基づく閾値での効果と、有限の閾値近傍を無作為化とみなす設計の平均効果は対象も仮定も異なる。近傍の割当過程に根拠がなければ後者の無作為化推論を自動的に適用しない。

奨学金の採点閾値で就学を比較する場合、全員が規則どおり受給する制度では結果の跳びを、受給に不遵守がある制度では受給確率の跳びで割ったfuzzy効果を使う。採点の支持が閾値の両側から近づき、潜在結果の条件付き平均が連続なら、その極限の差を対象とする。離散的な採点では利用可能な点と制度を用いて比較を定め、再審査や同じ閾値で変わる他制度も割当過程に含める。有限幅の受験者を対象にするなら、その幅内の割当確率に根拠を持つ局所無作為化設計を定める。「fuzzy regression discontinuity robust bias corrected」「discrete running variable local randomization」「weak first stage cutoff」を検索し、econ-designで対象と帯域・推論を選びecon-dataに引き渡す。
