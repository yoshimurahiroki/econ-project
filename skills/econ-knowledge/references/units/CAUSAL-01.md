## CAUSAL-01　潜在結果と調整

潜在結果を \(Y(1),Y(0)\)、観測を \(Y=DY(1)+(1-D)Y(0)\) とする。ATEは \(E[Y(1)-Y(0)]\)、ATTは \(E[Y(1)-Y(0)|D=1]\) である。集団、期間、結果尺度が対象の一部となる。各個体の潜在結果が他個体の割当に依存せず、観測結果が実際に受けた処置に対応する整合性を置く。

\((Y(1),Y(0))\perp D|X\) と \(0<e(X)=P(D=1|X)<1\) の下で、ATEは \(E[m_1(X)-m_0(X)]\) に等しい。\(m_d(X)=E[Y|D=d,X]\) である。

同じ条件下でATTは \(E[m_1(X)-m_0(X)\mid D=1]\) となり、平均を取る共変量分布がATEと異なる。ATTの平均だけなら、処置群の未処置結果についての条件付き平均交換可能性と、処置群の支持上で比較群が存在することでも足りる。対象の重みを変えることは、識別に必要な比較と外挿の範囲を変える。

因果効果を推定するマッチングは、処置前共変量が近い処置・対照個体を対応付け、相手群の結果から反実仮想を構成する。処置確率で対応付ける方法を傾向スコアマッチング（propensity score matching, PSM）と呼ぶ。傾向スコア $e(X)$ は $X\perp D\mid e(X)$ を満たす。上の交換可能性と支持を合わせると、$(Y(1),Y(0))\perp D\mid e(X)$ が成り立つ。処置個体 $i$ に対応する対照群の重みを $w_{ij}\ge0$、$\sum_{j:D_j=0}w_{ij}=1$ とすれば、ATTのマッチング推定量は
\[
\widehat{ATT}=\frac1{N_1}\sum_{i:D_i=1}\left(Y_i-\sum_{j:D_j=0}w_{ij}Y_j\right)
\]
となる。ATEでは対照個体についても処置時の結果を再構成し、両群を対象集団の構成で平均する。距離、対応人数、対照個体の再利用と許容距離を指定し、対応後の共変量分布を比較する。支持による除外を行う場合は、保持する集団のATEまたはATTを定義する。

[DoWhyの対応実装](https://github.com/py-why/dowhy/blob/0a05bc12f0d888f843795ccc29f56237ac002c0b/dowhy/causal_estimators/propensity_score_matching_estimator.py)は、傾向スコアの最近傍1個を復元抽出で選ぶ。`estimate_effect` は観測値 `D == 1` と `D == 0` で群を分け、どちらの群を対象にしても1の結果から0の結果を引く。ATTは処置群、ATCは対照群でこの差を平均し、ATEは両者を標本の群割合で集計する。`treatment_value` と `control_value` は返却値の対比ラベルに入る。引数だけを入れ替えても計算方向は変わらない。この符号化には `treatment_value=1, control_value=0` を指定し、逆向きの対比は対象集団を固定して差の符号を反転する。許容距離で対象を除外する分析には、その条件に対応する推定器を使う。

標的介入は適格性、開始時点、代替処置、追跡、終了、結果を同じ時点定義で指定する。これによって処置開始まで生存する時間を誤って処置効果へ入れる構成を除く。

例えば \(P(X=0)=P(X=1)=1/2\)、未処置平均が \((1,5)\)、処置効果が \((2,4)\)、処置確率が \((0.8,0.2)\) とする。各 \(X\) 内で交換可能なら標準化ATEは \((2+4)/2=3\)。処置群の \(X\) 構成は \((0.8,0.2)\)、非処置群は \((0.2,0.8)\) なので、観測平均はともに4.2で単純差は0となる。対象人口への標準化は、この共変量構成の差を取り除く。条件付き交換可能性は、処置への選抜と結果の生成を定める制度・構造から判断する。

この例で同じ $X$ 同士を対応させると、ATTは $.8(2)+.2(4)=2.4$、ATCは $.2(2)+.8(4)=3.6$ となる。各群の人口割合は半分なので、両者を合わせたATEは3である。参加から非参加への変更を評価すると、全員での平均は $-3$、元の参加者での平均は $-2.4$ となる。非参加を新しい処置として群も入れ替えれば、新しいATTの対象は元の非参加者であり、値は元のATCの符号を反転した $-3.6$ となる。

職業訓練の対象者全体の平均効果にはATE、実際の参加者についての平均効果にはATTを使い、訓練前の雇用歴と参加資格を揃える。同じATEの推定には結果回帰を人口分布で標準化する方法、処置確率の逆数で重み付ける方法、両者を組み合わせる二重頑健スコアがある。各方法で必要な条件付き平均、処置確率と支持を調べ、極端な重みにより対象を変更する場合は変更後の人口を定義する。「ATE ATT target population」「outcome regression inverse probability weighting」「overlap doubly robust」を手掛かりに、制度の選抜条件と同じ集団を扱う先行研究を探す。econ-designで比較と調整集合を定め、econ-dataで対象に対応する推定と推論を実施する。

因果DAGは、変数間の生成順序を有向非循環グラフで表す。構造因果モデルは \(V_j=f_j(Pa_j,U_j)\) と外生変数の同時分布から観測分布を定め、共通の外生要因を潜在共通原因として図に含める。介入 \(do(D=d)\) は処置の構造式を定数 \(d\) に置き換える。グラフでは \(D\) への入辺を切断し、処置から結果へ向かう生成経路を残す。

集合 \(Z\) が \(D\) と \(Y\) をd分離するとは、両者を結ぶ全経路を、\(Z\) に含まれる非コライダー、または自身も子孫も \(Z\) に含まれないコライダーで遮断することである。コライダー自身やその子孫への条件付けは、そのコライダーで遮断されていた経路を開く。総効果のbackdoor基準は、\(Z\) が処置の子孫を含まず、処置からの出辺を切ったグラフ \(G_{\underline D}\) で \(D\) と \(Y\) をd分離することである。観測された \(Z\) と支持条件から \(p(y\mid do(d))=\sum_z p(y\mid d,z)p(z)\) を得る。媒介変数を通常の調整集合へ入れると、総効果を伝える経路が遮断される。

処置と結果に潜在共通原因がある場合、観測媒介変数 \(M\) がfrontdoor基準を満たせば、その媒介経路から総効果を識別する。条件は、\(D\to Y\) のすべての有向経路が \(M\) を通ること、\(D\to M\) のbackdoor経路が空集合で遮断されること、\(M\to Y\) のbackdoor経路が \(D\) で遮断されることである。離散変数で、式に用いる各 \((d',m)\) に \(p(d',m)>0\) を置くと、

\[
p(y\mid do(d))
=\sum_m p(m\mid d)\sum_{d'}p(y\mid m,d')p(d').
\]

内側の和は媒介変数の効果を処置の人口分布で調整し、外側の和は処置が変える媒介変数の分布で平均する。連続変数では和を積分に置き換える。この条件と式は [Jeong・Tian・BareinboimのDefinition 1と式(3)](https://causalai.net/r85.pdf) に対応する。

仮想の職業訓練で、\(D\) を参加、\(M\) を資格取得、\(Y\) を就職とし、いずれも二値とする。採用するグラフは \(D\to M\to Y\) と \(D\leftarrow U\to Y\) であり、潜在変数 \(U\) は参加動機である。\(P(D=1)=1/2\)、\(P(M=1\mid D=0)=1/4\)、\(P(M=1\mid D=1)=3/4\) とし、観測条件付き就職率を次のように置く。

| 条件付き就職率 | \(D=0\) | \(D=1\) |
| --- | --- | --- |
| \(P(Y=1\mid M=0,D)\) | 0.14 | 0.26 |
| \(P(Y=1\mid M=1,D)\) | 0.54 | 0.66 |

frontdoor式の内側の平均は \(M=0\) で0.20、\(M=1\) で0.60となる。したがって介入後の就職率は、非参加で \((3/4)0.20+(1/4)0.60=0.30\)、参加で \((1/4)0.20+(3/4)0.60=0.50\)、ATEは0.20である。観測平均は非参加0.24、参加0.56で差は0.32となる。媒介経路を使う計算が、参加動機による選抜を含む観測差から介入効果を取り出す。

DoWhyでは、[`CausalModel`](https://github.com/py-why/dowhy/blob/0a05bc12f0d888f843795ccc29f56237ac002c0b/dowhy/causal_model.py) の生成時に`data`、`treatment`、`outcome`、`graph`を与え、`model.identify_effect()`で識別対象を得る。観測変数は渡したデータの列から定まる。同版の [`check_valid_backdoor_set`と`do_surgery`](https://github.com/py-why/dowhy/blob/0a05bc12f0d888f843795ccc29f56237ac002c0b/dowhy/graph.py) はbackdoor検査の出辺切断と介入の入辺切断を別引数で扱い、[`identify_frontdoor`](https://github.com/py-why/dowhy/blob/0a05bc12f0d888f843795ccc29f56237ac002c0b/dowhy/causal_identifier/auto_identifier.py) は上の三条件を検査する。econ-designで制度と時点からグラフを定め、econ-dataで識別式の条件付き分布を推定し、同じ対象人口へ集計する。検索では「structural causal model d-separation」「backdoor adjustment set」「frontdoor identification」を使い、各経路を成立させる測定と制度上の関係を原資料で調べる。

frontdoor条件を満たす単一の処置と媒介変数について、共通係数の線形条件付き平均を $E[M\mid D=d]=a_0+ad$、$E[Y\mid M=m,D=d']=b_0+bm+cd'$ とする。上の識別式へ代入すると、介入後の平均は $b_0+b(a_0+ad)+cE[D]$ となる。したがって、処置を $d_0$ から $d_1$ へ変える総効果は
\[
E[Y\mid do(d_1)]-E[Y\mid do(d_0)]=ab(d_1-d_0)
\]
である。媒介変数の変化 $a(d_1-d_0)$ に、媒介変数一単位当たりの結果変化 $b$ を掛ける。両回帰の設計行列が列フルランクなら、観測された条件付き平均からこれらの傾きを推定できる。

固定版DoWhyの [`TwoStageRegressionEstimator`](https://github.com/py-why/dowhy/blob/0a05bc12f0d888f843795ccc29f56237ac002c0b/dowhy/causal_estimators/two_stage_regression_estimator.py) は、このグラフに対して既定の線形回帰で $M$ を $D$ に、$Y$ を $M$ と $D$ に回帰する。`estimate_effect` は同じ`control_value`と`treatment_value`を両段階へ渡し、各段階の平均予測差を掛ける。[各回帰の計算](https://github.com/py-why/dowhy/blob/0a05bc12f0d888f843795ccc29f56237ac002c0b/dowhy/causal_estimators/regression_estimator.py)を $\Delta=d_1-d_0$ で表すと、返り値は $(a\Delta)(b\Delta)=ab\Delta^2$ となる。$a=2,b=3$、$0\to2$ の介入では返り値24に対して上の総効果は12であり、$1\to0$ では返り値6に対して総効果は $-6$ である。

econ-dataは、採択した条件付き平均と介入値に対応する計算を選ぶ。上の線形モデルでは回帰係数の積 $ab$ に元の介入差を一度掛け、傾き・介入差・結果尺度を同じ計算結果に残す。非線形の条件付き平均を採択した場合は、frontdoor識別式に沿って条件付き分布を推定し、媒介変数と処置の分布で積分する。

処置 $D$ が結果 $Y$ に作用する経路が $D\to M_1\to Y$ と $D\to M_2\to Y$ の二つあり、$D$ と $Y$ に潜在共通原因があるとする。片方の媒介変数だけを使うと、もう片方の有向経路が残る。組 $M=(M_1,M_2)$ が上の三条件を満たすとき、frontdoor式の外側の和には二変数の同時分布 $p(m_1,m_2\mid d)$ を使う。DoWhyの識別器はこの組も検査する。固定版の二段階回帰は複数の媒介変数を渡すとエラーを返すため、共同媒介による総効果は上の識別式から計算する。

例えば $(M_1,M_2)=(0,0),(0,1),(1,0),(1,1)$ の条件付き確率が、$D=0$ では $(.4,.1,.1,.4)$、$D=1$ では $(.1,.4,.4,.1)$ とする。各組について処置の人口分布で調整した結果平均が $.25+.5\,1\{m_1=m_2\}$ なら、二つの値が一致する割合は $.8$ から $.2$ に下がる。介入後の平均は $.65$ から $.35$ に変わり、総効果は $-.30$ となる。各媒介の周辺分布はどちらの処置でも半々であり、その積に置き換えると、この効果を0と計算してしまう。

個人の観測事実 $e$ に対応する反実仮想は、採択した構造因果モデルで外生変数を復元し、同じ外生変数の下で介入を実行して求める。手順はabduction・action・predictionの順となる。まず観測事実で外生変数の分布を $P(U\mid e)$ に更新する。各構造式が外生変数について可逆なら、観測された親変数と結果からその個人の $u_j$ を逆算する。次に処置の構造式を $D=d$ に置き換え、残る構造式と外生変数を保持して、グラフの生成順に介入後の変数を計算する。外生変数の各値で得た結果を $P(U\mid e)$ で集計すると、観測事実に条件付けた反実仮想分布を得る。

独自の計算例として、$D=U_D$、$Y=(1+D)U$ とし、$U_D$ と $U$ は独立、$U$ は $-1,1$ を同じ比率で取る。集団への介入 $do(D=0)$ の結果は $-1,1$、$do(D=1)$ の結果は $-2,2$ となり、ATEは0である。$D=0,Y=1$ を観測した個人では $U=Y/(1+D)=1$ と復元できる。同じ $U=1$ に対して $D=1$ を代入すると $Y(1)=2$、その個人の効果は1となる。集団の介入平均と観測された個人の反実仮想は、それぞれ外生変数の人口分布と観測事実に対応する外生変数を使う。潜在結果間の結合が個人別効果を定める関係は [ADVCAUSAL-06](https://github.com/yoshimurahiroki/econ-project-mini/blob/main/skills/econ-knowledge/references/chapters/12-causal-extensions.md#advcausal-06) を参照する。

[DoWhyの `counterfactual_samples`](https://github.com/py-why/dowhy/blob/50d43ac9c04a9ba301349530fac0ef34db59c9ec/dowhy/gcm/whatif.py) は、`observed_data` と `noise_data` のどちらか一方を受け取る。観測値を渡す経路は `InvertibleStructuralCausalModel` を使い、`compute_noise_from_data` で各個人の外生変数を復元する。外生変数を直接渡す経路は `StructuralCausalModel` を受け取り、両経路とも同じ外生変数を保持して生成順に再計算する。`interventions={"D": lambda _: 1}` は処置を1に固定する介入である。econ-designは、介入で保持する構造式と外生変数の結合を定める。econ-dataは、そのモデル、個人の観測値または外生変数、介入値を同じ計算へ渡し、事実の再構成値と反実仮想の結果を返す。
