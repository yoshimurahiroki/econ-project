# Select the official implementation

Select the required section through the [implementation index](implementation.md#select-the-operation-specific-rules). Read its complete body and registered prerequisites before applying it.

## Estimator, engine and algorithm selection

1. **Output: estimator contract; consumer: candidate selection.** Recover the adopted target, identification, outcome scale and sample from [estimand to method](../../econ-design/references/designs.md#choose-the-estimand-and-method). Carry fixed effects, instruments, treatment history, weights, inference and precision. Read the matching model contract's equations and the selected procedure's complete prerequisites. An unresolved function uses the [regression/causal](#regression-and-causal-implementation-candidates), [market](#market-model-implementation-candidates) or [dynamic/numerical](#dynamic-and-numerical-implementation-candidates) table; a settled function proceeds to step 2.
2. **Output: verified native call; consumer: implementation ranking.** From the selected interpreter, inspect the installed package version, callable signature and version-matched official documentation. Retrieve official source for a consequential unresolved behavior. Match the complete requested combination to the actual API and retain that correspondence in the existing result. Bind the selected [runtime/API contract](../../../harness/research.md#capture-the-selected-python-r-or-julia-environment) to the runner. Before: “The package supports IV.” After: “The selected call implements the adopted endogenous regressor, excluded instruments, absorbed effects, analytic weights and cluster covariance.”
3. **Output: selected implementation and environment; consumer: runner.** Rank compatible calls by mathematical agreement, required official functions, maintained revision and existing environment. Inspect the selected license and restore its dependency closure. Choose SQL, R, Python or Julia at the operation needing it, preserving step 1 across transfers. When resources determine selection, compare end-to-end time and peak memory, including scans, transferred data, conversion, startup and compilation. Retain the effective algorithm, precision and inference. A missing capability returns its exact requirement to the existing owner: compare a compatible call, a minimal extension of native fits/scores/solvers, or an authorized design change. Preserve fixed specifications and record actual failures internally.
4. **Output: actual fit and saved quantities; consumer: artifacts.** Execute the selected procedure and [result handoff](implementation-calls.md#fit-results-and-execution-handoff). Save the producing call, package/source identity, sample, effective options, convergence and requested native inference. A failed required calculation propagates its failure through the existing runner; resume its repair before producing dependent quantities. Before: “Import succeeded; report the coefficient.” After: “Fit the adopted specification, save its returned coefficient and covariance, then bind the table to those saved quantities.”

## Regression and causal implementation candidates

Use the following branches to find the eligible implementation. The listed functions are candidates tied to economic objects, not defaults that override the design.

| Required object | Specialist implementations to inspect | Choices that must match the actual call |
| --- | --- | --- |
| Linear projection, additive fixed effects, linear IV | R `fixest::feols`; Python `pyfixest.feols`; Julia `FixedEffectModels.reg` | Within variation, endogenous regressors and excluded instruments, absorbed effects, singleton/rank handling, weight type, covariance and small-sample convention. |
| Exponential conditional mean with nonnegative outcomes | R `fixest::fepois`; Python `pyfixest.fepois` | Exposure or offset, fixed effects, separation and omitted observations, convergence, supported weights and cluster covariance. Zeros alone do not require a different model. |
| A specified negative-binomial likelihood | R `MASS::glm.nb`; Python `statsmodels` negative binomial | NB1/NB2 or other adopted variance law, estimated dispersion versus a fixed GLM dispersion parameter, link, exposure and treatment of individual heterogeneity. Adding group indicators is an unconditional likelihood specification. |
| Binary panel slopes with unrestricted individual intercepts | Python [`statsmodels.discrete.conditional_models.ConditionalLogit`](https://www.statsmodels.org/stable/generated/statsmodels.discrete.conditional_models.ConditionalLogit.html) and its official `fit` | Binary outcome, individual `groups`, covariates without an intercept, within-individual identifying variation and dropped constant-outcome groups. Match the official covariance to the adopted independent units; solver keyword arguments do not supply arbitrary cluster inference. |
| Two-period ATT under conditional parallel trends | R `DRDID`: the corresponding panel or repeated-cross-section OR, IPW or DR function | Sampling structure, chosen score, covariates and constant, normalized sampling weights, overlap/trimming, nuisance estimation and valid influence-function or resampling inference. |
| Group-time ATT with staggered absorbing adoption | R `did::att_gt` and `aggte` | Cohort coding, comparison group, anticipation, panel versus repeated cross section, unbalanced-panel handling, covariate timing, weights, clusters and aggregation population. |
| Dose-specific ATT(d), marginal ACRT(d), or their event-time aggregation with fixed unit doses | R `contdid::cont_did` 0.1.2 and `ggcont_did` through the [continuous-DID contract](../../econ-design/references/causal-models/continuous-did.md#fixed-dose-continuous-did) | Fixed pretreatment and post-treatment dose, separate adoption cohort, balanced panel, level versus slope, standard versus strong parallel trends, dose versus event-study aggregation, spline/CCK conditions and official inference. |
| Effects of changing treatment paths or doses | R `DIDmultiplegtDYN::did_multiplegt_dyn` | Baseline treatment, switcher/control eligibility, observed paths and horizons, normalized versus non-normalized effects, restrictions for continuous treatment and cluster inference. |
| Departure from parallel trends in a saved event study | R `HonestDiD::createSensitivityResults_relativeMagnitudes` or `createSensitivityResults` | Universal reference, ordered pre/post coefficients, full covariance, adopted relative-magnitude or smoothness set and post-period contrast. |
| An adopted wild cluster bootstrap for a fitted linear model | R `fwildclusterboot::boottest` | Supported saved model class, null, clustering and bootstrap clustering, weight distribution, repetitions, null imposition and test-inverted interval. |
| Small-sample cluster inference for a supported fitted model | R `clubSandwich::coef_test` | CR adjustment, exact analysis-sample cluster vector, coefficient contrast and Satterthwaite or adopted reference calculation. |
| Local discontinuity or fuzzy-RD effect | R/Python `rdrobust` | Cutoff, sharp/fuzzy/kink design, bandwidth, polynomial order, kernel, bias correction, mass points and dependence. Extract the point estimate and interval belonging to the adopted inferential procedure. |
| Running-variable density at a cutoff; RD power or sample size | R `rddensity::rddensity`; `rdpower::rdpower`, `rdsampsi` or `rdmde` | Save the density diagnostic separately from the outcome effect. Power uses the adopted alternative effect, bandwidth, sample allocation, variance and RD inference procedure. |
| Linear IV or specified moment restrictions | R `ivreg` or `gmm`, or the matching FE-IV branch above | Instrument-to-regressor mapping, moment conditions, weighting matrix and dependence. Conventional 2SLS output does not supply weak-instrument-robust inference automatically. |
| A treated trajectory or treated-block average | R `Synth` or `synthdid` | Donor eligibility, pre-treatment fit, treatment timing, target aggregation and suitable inference. The documented `synthdid` matrix interface requires a common treatment block. |
| An orthogonal-score treatment parameter or potential-outcome functional | Python `DoubleML` through the [native score contract](../../econ-design/references/causal-models/heterogeneity.md#official-doubleml-fits) | PLR, DID, IRM, PLIV, IIVM, SSM, QTE, PQ, CVaR or APO; slope, ATE/ATT/LATE, quantile, tail or treatment-level mean; selection, nuisance learners, nested splits, weights and native inference. |
| Marginal quantile effects and counterfactual distributions | R `qte::unc_qte`, `qdid` or `cic` through the [causal contract](../../econ-design/references/causal-models.md) | QTE versus QTT, selection or distributional-trend restrictions, ranks, target population, distribution-first aggregation and supported resampling. |
| Economic quantities from a saved fitted model | R `marginaleffects` predictions, slopes and comparisons and their average functions | Actual evaluation population, variable contrast, response scale, averaging weights, fitted covariance, reference distribution and saved-fit identity. |
| Network exposure contrasts under Bernoulli assignment | Official `statspai.network_exposure` through the [network contract](../../econ-design/references/causal-models/networks.md#network-exposure-contrasts) | Known assignment probability, directed adjacency, exposure mapping, all-exposure eligibility, HT/Hajek target and native PSD HAC inference. |
| Identified treatment-effect sets | Official `statspai.manski_bounds`, `lee_bounds` or `balke_pearl` through the [bounds contract](../../econ-design/references/causal-models/networks.md#identified-sets-and-their-sampling-regions) | Population support, treatment/selection/instrument restrictions, exact trimming, retained selection denominators and the native sampling-region target. |
| Conditional treatment, instrument, multi-arm or survival effects | R `grf::causal_forest`, `instrumental_forest`, `multi_arm_causal_forest`, `causal_survival_forest` through the [GRF contract](../../econ-design/references/causal-models/heterogeneity.md#grf-heterogeneous-treatment-effects) | Conditional effect versus population aggregate; IV exclusion/compliance population, reference arm, censoring/horizon, honesty, nuisance fits, weights, clusters and native pointwise inference. |
| Randomized allocation and its design-matched inference | `randomizr::declare_ra`/`conduct_ra`, `balanced_ra`, `estimatr`, `DeclareDesign` through the [RCT contract](../../econ-design/references/causal-models/randomization.md#rct-design-assignment-and-diagnosis) | Assignment units, exact marginal probabilities, pretreatment balancing variables, population contrast and complete-assignment randomization inference. |
| Orthogonalized forest effects with explicit nuisance learners | Python `econml.dml.CausalForestDML` | Treatment coding, independent folds, nuisance learners, honest forest, effect covariates and target-population aggregation; use the saved official effect and aggregate inference. |
