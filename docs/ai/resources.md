# Task resources

## Select task inputs

Begin a new economics task through econ-workflow once, then select its executor from [the method index](compiled_ai_skills.md). Support methods and reference reads do not restart entry. Apply econ-assertive for prose; when the requested writing operation needs examples, use its profile precedence and the preference in [project context](repo_context.md). Read only support that supplies a dependency of the requested result. The presence of optional support or reference resources alone does not require reading or executing them.

- Use econ-design for economic questions, incentives, models and empirical comparisons.
- Use econ-literature for literature, institutions, novelty and citation verification. Use econ-paper to explain a source paper.
- Use econ-data for acquisition, measurement, code and reproducible numerical outputs.
- Use econ-writing for papers, research content, presentations, translations and exhibits. Use econ-assertive for prose and econ-edit for requested revision.
- Use econ-review for independent assessment. Use econ-style for requested writing-profile changes.
- Use econ-workflow for the common entry and to coordinate interdependent work and resume integration. Use econ-handoff for a requested transfer.

## Evidence and requested external-method adoption

Read the existing project records, original sources and saved results that establish the requested answer. For requested external-method adoption, inspect the implementation, permission and license terms, functional files and dependencies. Verify its behavior in the authorized environment before adopting it. Software licensing does not establish model access or permission to incur charges.

## Records and distribution

Keep implementation comparisons, private collection records and operational history outside published artifacts. Preserve source identities and claim locators in the evidence records. Preserve [third-party notices](../../THIRD_PARTY_NOTICES.md) with distributed material governed by those notices. Apply econ-assertive's common prose rule to reference-derived writing.
