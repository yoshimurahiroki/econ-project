# Shared work, resumption and handoff

## Shared work

One agent owns and integrates the requested result. Delegate a distinct subtask when separate expertise or parallel work improves the result or completion time. Give each worker the objective, binding constraints, exact inputs, applicable rule versions, write scope and concrete output. Each worker reads the required rule bodies and completes CORE's reasoning, execution and integrated review for its assignment. Assign one writer per shared file or explicit nonoverlapping regions.

Assign work that resolves a determining parent claim or removes its execution obstacle. Keep dependent operations in prerequisite order and parallelize independent retrievals or changes. For a comparison requiring independent judgment, supply the question and source inputs before sharing an adopted conclusion; integrate the returned evidence at the disputed premise.

## Return and integration

Return the substantive result, changed paths, source references and actual execution outcomes to the owner. The owner reconciles interfaces and dependencies and reviews the assembled result. Reuse completed work and give the user one integrated response. Keep coordination inside the existing conversation or task record.

## Retry and capacity

For an interrupted external write, read the target and its operation status before retrying. Repair the cause of a returned failure and retry the affected operation within the existing permission and retry policy. Preserve completed independent results. Choose worker counts from available capacity and actual separable work.

## Resumption

Resume from the original objective, adopted constraints, current source versions, completed results and remaining work. Read required text that has changed or was never read. Reuse unchanged completed operations and the existing persistent record when continuation requires one.

## Handoff

Transmit the objective, fixed constraints, source version, completed results and remaining authorized work. Point to the canonical specification and outputs; include the exact input or permission required for the next dependent action.

## Requested usage accounting

Collect usage, cost or worker statistics when the user asks for them.

## Review findings and independence

Use independent review when expressly selected or required by the platform. Preserve its evidence, actual identities and role separation under CONTROL. The task owner performs the integrated completion review required by CORE in every workflow.

## Paragraph assignments

Assign writing by coherent arguments or sections with distinct sources. The editorial owner preserves terms, source correspondence and logical dependencies across the assembled prose, then completes the integrated review. Use the same econ-writing workflow in delegated and single-author work.
